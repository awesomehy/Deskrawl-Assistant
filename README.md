# Deskrawl 装备助手

为 Deskrawl 提供装备筛选、物品整理与自动刷图的 Windows x64 工具。使用独立窗体，无需安装 Python。当前版本：**v1.3.8**。

修复神话裂隙观星计划匹配与回城中断后的恢复；死亡时等待游戏原生复活，传说装备筛选按职业显示实际随机词条池。[本版说明](docs/1.3.8验收说明.md)。

如果觉得本软件对你有帮助，欢迎在 [GitHub 项目](https://github.com/awesomehy/Deskrawl-Assistant) 点亮 **Star**！

## 下载与使用

**[下载 v1.3.8 exe](https://github.com/awesomehy/Deskrawl-Assistant/releases/download/v1.3.8/Deskrawl-Assistant-v1.3.8.exe)** · [全部 Releases 与更新记录](https://github.com/awesomehy/Deskrawl-Assistant/releases)

1. 下载并双击 exe；启动游戏、进入角色，在助手顶部点击“连接游戏”。主城和战斗场景均可使用。
2. 在“装备筛选规则”中配置并启用规则，到“背包与仓库”检查结果，按需开启持续监控和自动整理。
3. 需要自动刷图时，在“托管模式”配置关卡、换装和奖励处理策略，保存后手动启动。

缺少 WebView2 时，请安装[微软官方运行时](https://go.microsoft.com/fwlink/p/?LinkId=2124703)。已有版本可通过顶部“一键更新”升级；手动升级请先保存设置并退出旧版。v1.1.5 / v1.1.6 用户首次升级需手动下载最新版。

## 核心功能

| 页面 | 可以做什么 |
| --- | --- |
| 装备筛选规则 | 按职业、部位选择传说装备，配置多套主／副词条组合；至少命中指定数量即保留，支持导入、导出和复制规则。 |
| 背包与仓库 | 查看角色属性、穿戴装备、词条及宝石；显示换装战力预估，支持可交易筛选、Steam 市场参考价、自动锁定、双向搬运与分区整理。 |
| 托管模式 | 自动换装、推图或双图轮刷、观星刷高价值奖励、回城整理与掉落统计；支持神话裂隙、碎片消费、成长预设及宝石／符文自动合成。[本版说明](docs/1.3.8验收说明.md) |
| 掉落预览 | 进入在线关卡后查看各波次计划物品、效果和分组词条，命中高亮；支持高价值掉落原始数据留档。[使用说明](docs/掉落预览说明.md) |
| 日志 | 查看新增物品、锁定、搬运及操作记录，支持搜索与历史查询。 |
| 交流&反馈 | 查看QQ群二维码和群号，交流游戏心得与反馈使用问题。 |

## 兼容性与数据

已验证基准为 **Deskrawl 1.0.3 / Steam build 25973417**。支持普通名称、序号与地址变化的自动检测适配；新增资源、结构或逻辑变化需要维护。掉落预览与托管原生动作有独立构建校验，未适配时停用。

托管固定保留神圣、黑雾装备，并将所有符文、宝石、金条和传说缰绳强制收纳；神圣装备不自动穿戴。每类收纳至少选一个已解锁仓库页，满仓时保留在背包并暂停等待。先完成整批筛选锁定，再处理垃圾，主城奖励未清空时不入图。新用户默认装备存放第 1／2／3 页、符文第 4 页，宝石、金条和传说缰绳第 5 页，仅使用已解锁格位。

宝石、符文自动合成正式开放，新旧用户默认关闭；分别设置最高产出品质，符文可指定跳过种类。仅在主城整理时合成，锁定、装备中和跳过的材料不参与；符文概率合成失败也会消耗材料，已有等级与经验不保留。Steam 换算报价标为参考价，实际交易以 Steam 为准。

换装战力按固定单体 Boss 场景估算，不能完整模拟暗金特效与实际 DPS。掉落预览是尚未结算的计划，实际获得以游戏为准；宝箱内部和额外收益不提前推测。

规则、设置和日志保存在 `%LOCALAPPDATA%\Deskrawl装备助手\`，更新后保留；新启动不会自动连接或开启监控、整理、托管。顶部显示游戏运行状态，可通过 Steam 启动游戏，关闭游戏需二次确认。图标与必要资源全部内置，个人数据不随程序分发。
