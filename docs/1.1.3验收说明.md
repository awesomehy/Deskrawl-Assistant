# 1.1.3 验收说明

适配 Deskrawl 1.0.2（Steam build 25817367）。程序使用独立窗体，保留已有筛选规则；自动整理初始暂停。

## 本版功能

1. **背包 / 仓库互转**：勾选实体物品后整组移动，保留装备词条、强化、编号与锁定状态。
2. **马车自动收取**：在「背包与仓库 → 自动整理」按名称搜索和勾选物品，支持多选；当前类型及搜索结果可一键全选 / 全不选，其他筛选范围的选择保留；只收取选中的实体物品。
3. **宝石自动入库**：优先合并同种同等级宝石，读取游戏上限（新版为99），剩余数量使用空格。
4. **背包容量整理**：按实际物品占用格数判断，配置剩余空格触发值及预留空格目标，支持全部 / 已锁定 / 未锁定装备范围。
5. **宝石 / 符文预览**：36种宝石、199种符文的内置图标；宝石按镶嵌部位显示效果，符文显示1级基础值与成长、技能及套装效果。

## 测试入口

打开「背包与仓库」，展开「自动整理」。先保存设置，再启动自动整理。三项功能各自可选，新增装备锁定监控另有开关。停止、断开连接、退出或全部解锁会暂停自动操作；重新打开助手保留偏好并默认暂停。

建议先分别测试每项，再同时开启。背包满时马车物品保留，仓库容量不足时等待。按数量及格位检查宝石堆叠，并核对装备搬运前后的词条、强化和锁状态。

持续监控只锁定开启后新增且符合规则的装备；开启前已在背包 / 仓库的装备请使用「一键按规则锁定」。战斗中物品变化造成读取不同步时，工具最多即时重读三次；仍在变化则保留开关和待锁装备，下一轮继续检查。数据布局或稳定数据的完整性错误仍停止自动操作。

## 游戏 1.0.2 的适配内容

- 新增48种技能符文（24种普通、24种宏伟）；武器与宝石种类没有增加。
- 重建注册表和类型字段校验，更新保存标记、角色及仓库入口、GC引用写屏障地址。
- 重提取装备 / 符文 / 宝石字典、图标、效果和词条池，更新旧符文套装效果文本。
- 随机主、副词条池不变；固定护甲、武器伤害和速度继续排除。
- 宝石堆叠上限从50提高到99，工具按游戏数据动态读取。

符文目前显示1级基础效果和成长说明，不显示特定符文实例的实际等级效果，也不判断当前角色是否激活了套装。
