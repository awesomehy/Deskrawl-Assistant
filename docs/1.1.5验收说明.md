# v1.1.5 验收说明

v1.1.5 发行版，适配 Deskrawl 1.0.2。安装与回退已完成独立验证；玩家对后续正式版本的一键升级验收将在发布更高版本后进行。

## 更新功能

启动 3 秒后检查本项目 GitHub 的最新正式 Release，之后每小时检查一次。顶部「检查更新」可手动检查，连续点击有 60 秒冷却；网络失败、没有新版本或 GitHub 限流均不影响装备功能。

发现新版本时显示版本号和「下载并更新（重启）」。点击后先保存合法的规则、整理设置，再将新 exe 下载到当前程序目录。核验文件大小、GitHub 提供的 SHA256、Windows x64 格式和程序版本号，成功后暂停并等待当前游戏操作结束，退出旧窗体、替换文件并启动新窗体。当前文件名及原路径保留，个人配置和日志仍在用户数据目录。

下载或核验失败不替换文件；替换期间保留旧程序备份。新窗体确认加载后清理备份，不能确认启动时尝试恢复并启动旧程序。需要对当前程序目录有写入权限，源码模式仅提供更新信息，不能替换 Python。

首次使用更新功能需要安装 1.1.5；1.1.4 没有更新检测。最新版与当前版本相同时不会出现更新按钮；发布高于当前版本的正式 Release 后才出现。

## 主词条全中

1. 同件装备的某个启用组合勾选四条实际随机主词条，并满足主词条数量条件。
2. 「背包与仓库」清单及详情应显示金色「✦ 主词条全中」及组合名称；筛选菜单可选择「主词条全中」。
3. 故意配置不匹配的副词条。特殊标记仍显示，但整件装备的规则结果和自动锁定仍检查副词条。
4. 将四条主词条分散到两个组合，每个组合只包含其中三条：即使两套规则都达到三条门槛，也不显示全中标记。
5. 基础护甲、武器速度及武器伤害不计数；只有三条随机主词条、组合停用或主词条读取不完整时不标记。

## 已完成验证

- 232 项自动检查通过，包含公开正式版本选择、数值版本比较、下载来源与重定向、大小及哈希、下载中断、文件权限、版本不符、原文件保留、未保存配置保护，以及 Windows 刚启动时的首次检查。
- 全中标记独立于副词条和锁定判定，不拼接不同组合；基础护甲在实际服务预览中单独排除。
- 独立中文及空格目录内完成下载、替换和新窗体重启；真实单文件 exe 占用文件时，等待退出后替换，确认新窗体加载后清理备份。原文件名、目录、规则文件和日志保留。
- 替换前篡改暂存文件，二次校验拒绝安装，旧 exe 原样保留并重新打开。模拟新版本无法确认启动时，仅停止本次启动的测试程序，恢复旧 exe 并重新打开。
- 以上安装验证使用本地发行程序和模拟下载流，不发布或伪造 GitHub 发行版。真实 GitHub 检查、公开 v1.1.4 下载、大小 / SHA256 / Windows 格式 / 程序版本校验也已通过，未运行或安装下载的程序。当前没有高于 1.1.5 的公开版本，日常界面不会显示模拟的新版本。
- 1280×820 与最小 980×680 界面均验证全中标记、独立筛选和更新前保存，无横向溢出或页面错误。

实现采用 [GitHub 官方 Release API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release) 获取本项目的正式发行版和程序校验信息，不读取用户 GitHub 凭据。
