# v1.1.6 功能与验收说明

本版新增词条组合管理、导入状态选择和跨装备复制。适配 Deskrawl 1.0.2。

## 组合删除

在装备编辑器顶部选择已保存组合，点击「删除当前」，确认后只移除该组合。通过「管理组合」可勾选多个组合、全选 / 全不选、一次删除；删除最后一个组合后可以重新新增。删除其他组合时，当前未保存的编辑仍保留。旧版共用组合按当前装备移除关联，其他装备继续保留。

## 规则导入

选择 JSON 后显示组合数量及「导入后状态」：停用（默认）或启用。状态只作用于本次导入的全部组合；原有组合和状态保留。取消导入不会写入。导入后立即刷新编辑器与启用数量。

## 跨装备复制

在来源装备点击「复制到同类装备」，选择当前或全部已保存组合、同一部位的目标装备，以及追加（默认）或替换。名称、主副词条、数量条件与启用状态保留，新组合使用独立编号。

追加保留目标已有组合；替换清理目标关联后复制。名称、状态和条件都相同的组合会跳过，避免重复复制产生冗余。不会复制未保存的改动，也不会放弃当前编辑。复制时目标已有组合变化会阻止替换，重新打开复制窗口后重试。

## 验证

249 项自动检查通过，覆盖导入启用选择、持久化、同部位复制、当前 / 全部组合、追加 / 替换 / 去重、来源和其他装备保留、删除最后一个组合、批量删除失败不产生部分修改，以及旧版共用规则和数值规则。

隔离配置的界面实测通过：保留未保存编辑、导入启用 / 停用、当前 / 全部组合复制、追加 / 替换、单个 / 批量删除及删除最后一个组合后重新新增。复制窗口在 980 × 680 的最小窗体尺寸下可完整操作，未出现页面脚本错误。

单文件 exe 的独立窗体启动、重复启动复用服务、配置与日志重启保留，以及实际游戏只读连接均通过。新版脚本和组合操作也在打包后的 exe 中用隔离配置验证。已核对 22 个内置代码模块、458 个资源、444 张图标与更新替换脚本均与当前源码一致，未打包个人规则或背包数据。
