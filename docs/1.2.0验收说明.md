# 1.2.0 整合验证

2026-10-10，合入 [PR #1](https://github.com/awesomehy/Deskrawl-Assistant/pull/1) 的当前角色刷图推荐与实测经验收益。源码版本、窗体版本、Windows 版本资源及构建脚本均为 1.2.0；本记录对应整合检查，GitHub 发行包尚待发布。

## 修复

- 新增经验与推荐读取接入 1.1.8 的统一适配结果，不再只接受旧游戏哈希或固定旧入口。重新提取当前类型信息，新增单例和难度状态地址定位，并纳入字段布局、枚举、资源、原生代码和连接期间文件变动核验。
- 重开耗时明确区分自动观测和手动指定，模式随设置保存；明确填写的 8 秒也不会被自动观测中位数覆盖。
- 非正数计划经验回退使用同一快照里的当前等级和经验倍率，避免沿用开局属性。正数计划奖励直接累计，回退估计在页面标明来源。
- 游戏炼狱计划名 `Inferno1` 与模型 `Inferno` 统一，避免推荐读取误报关卡身份不稳定。
- 解决 README、网页入口、打包配置及打包检查冲突，同时包含原有兼容性基准、Capstone 动态库和新增三个数据文件。

## 自动检查

Windows x64 / Python 3.12.14：431 项 unittest 全部通过。包含既有装备、搬运、整理、日志、规则与更新检查，以及普通经验跨升级、完整时间预算、地图准入、普通波与 Boss 波校准、失败收益、配装隔离、计时保护、手动耗时优先和当前属性回退。

JavaScript 语法检查通过。重新从 Deskrawl 1.0.2a / Steam build 25842017 提取推荐静态资源：76 张地图、71 张参与排序的常规地图、65 种怪物；地图、敌人、难度和计算配置与贡献版本一致。

在 `build/` 中的游戏文件副本改动保存字段 `nly → zzz`、注册表 `gj → zz`、难度状态 `ey → xy` 和角色管理入口地址。自动适配通过，经验与推荐 profiles 使用新字段、类型名及哈希；真实安装目录未修改。

## 独立程序与实机

- 通过 PyInstaller 6.22.3 构建 Windows x64 单文件程序，版本 1.2.0。在独立中文及空格目录运行，清除外部 Python 路径，WebView2 窗体正常加载。
- 验证 444 张图标、235 种宝石 / 符文说明、经验字段、推荐字段、地图目录、兼容性基准及依赖全部内置；个人规则、装备快照、SQLite 数据库和游戏 DLL 未包含在程序中。
- 验证多套装备规则、整理偏好、日志、经验样本及推荐设置重启后保留。重复启动复用服务；重启后不自动连接、锁定或整理。
- 打包程序只读连接正在运行的 1.0.2a 游戏，读取完整背包 / 仓库，取得当前角色和炼狱关卡，生成71张常规图比较及可进入地图推荐。完整清单与推荐后台分别完成，打包检查等待首个稳定推荐快照。
- 隔离网页检查确认手动8秒模式可以编辑、保存并刷新后保留；实机推荐卡片显示「重开开销 8 秒 · 手动指定」，无前端脚本错误。

验证过程关闭测试实例的监控和自动整理，仅使用外部只读读取；未锁定、转移物品或修改真实游戏内存、存档及用户配置。
