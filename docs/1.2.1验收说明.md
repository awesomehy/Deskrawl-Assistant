# v1.2.1 发布验收说明

发布版本为 v1.2.1，已验证基准为 Deskrawl 1.0.2a / Steam build 25842017。代码读取角色、穿戴装备、宝石与属性时仅使用外部只读访问；换装预览不更换游戏装备。

## 用户可验收的内容

1. 打开“背包与仓库”：上方显示角色名称、等级、职业、职业主属性、单体 Boss 基准战力和主要属性；展开后可查看完整属性以及 12 个穿戴部位。点击身上装备在独立弹窗查看词条和宝石，关闭后保留原列表侧栏预览。
2. 装备列表显示远古、黑雾、神圣独立标签；同一件装备的多个标签同时保留。强化显示 +n；孔位显示镶嵌数量 / 总孔数。
3. 点击有宝石的装备：预览显示每颗宝石的图标、名称和在该装备部位生效的属性。武器、护甲、戒指与项链的宝石效果分别选择对应类别，不对宝石加算装备强化。
4. 查看换装列的攻击力增减值与比例，再点击装备查看换前、换后和各项属性变化。戒指默认显示收益较高的位置，可在详情切换“戒指 1 / 戒指 2”。
5. 点击七个表头的 ▾：位置可筛选背包 / 仓库并按格号排序；物品等级、强化、总孔数、攻击力提升值可升序 / 降序排序；锁状态可筛选已锁定 / 未锁定；规则结果可筛选符合规则 / 不符合规则 / 主词条全中。多列条件取交集，同一列多选取并集；“不符合规则”不包含待核验。全不选后应用显示空列表，全选后应用恢复该列全部物品，清除此列只移除此列的设置。未知数值在升降序中都排到末尾。上方一键清除筛选 / 排序；更多条件仍支持职业、部位、标签等。
6. 筛选不会改变勾选的物品或批量操作范围。当前列表以外仍有勾选时，界面显示隐藏勾选数量。已穿戴装备只供预览，不进入背包 / 仓库搬运与锁定选择。

## 计算范围

攻击力按游戏 EquipmentUI.gdw / gdx 的面板公式计算：武器伤害与固定伤害、职业主属性、攻击速度、暴击期望及三组加权伤害系数相乘，最后截断为整数。战士使用力量，法师使用智力，猎人和武僧使用敏捷；暴击伤害按额外暴击伤害参与计算。

当前属性组合保留基础值、装备 / 天赋 / 符文缓存、百分比层、状态增益、属性转换及已生效的条件增益。生命比例严格按 <30% / >80% 判定；附近敌人距离按游戏忽略竖直轴的判断处理，半径边界算附近，状态条件使用游戏默认 6 米半径。Unity 引擎版本或坐标结构不能核实时，角色计算暂不可用，不使用零值代替。

换装估算重新组合永久属性，并固定为**角色满血、一个 Boss、处于战斗、无临时增益**；战士 / 武僧与 Boss 相距 2 米，猎人 / 法师 7 米。满血、单敌人、战斗条件按此场景启用，低血量、多敌人条件关闭，距离条件按固定距离判断（半径边界仍算附近）。状态层数、状态限定转换、指定技能施放时的条件属性不计入。临时 Buff、实际生命、距离、敌人数量均不影响基准战力或换装提升；升级、换装、强化、宝石、天赋等永久属性变化会重新计算。

换装只替换两件装备的强化词条与各自已有宝石。因此**不会预测换装后新传奇特效、技能等级、技能触发或真实战斗 DPS**，固定场景得分也不是当前游戏战斗面板的读数。无法读取完整装备、未知宝石、未知计算类型、转换循环或职业不符时不给出伪造的收益数值。角色的其他属性仍按当前状态显示，约每 2 秒读取一次。

## 验证

- 461 项 Python 自动测试通过，覆盖原有功能、角色计算、镶嵌宝石、戒指双位置、断线清理、坐标层级，以及固定 Boss 条件、临时状态隔离和永久属性重新计算。
- 12 项 Node 前端测试通过，覆盖多列筛选、多选并集、全不选、未知状态、格号、总孔数与强化升降序、材料占位值排除、未知收益排序及不修改原始数据。
- 实际游戏只读验证读到当前角色的 12 件装备；穿戴武器的三颗无瑕钻石按武器类别显示每颗 +35% 物理伤害。
- 实机连续 8 次采样中，固定 Boss 基准战力和整张清单的换装提升值保持一致。浏览器验证了七个表头菜单、多列组合、全选 / 全不选、取消草稿、逐列清除和全部重置；穿戴武器弹窗正确显示宝石，关闭后列表侧栏预览保持原选择。
- 本地 WebView2 窗体用于玩家验收，监控与自动整理启动时仍默认暂停；本轮验证没有执行锁定、移动或实际换装。
- 发布单文件 exe 验证了独立窗体启动、中文及空格路径、没有外部 Python 的环境、重复启动和规则 / 日志 / 经验样本持久化；另以后台方式完成实际游戏只读连接、角色装备和固定战力预览验证。内置模块、网页、全部 444 张图标和静态资源已逐项与发布源码核对，未打包个人配置和快照。
- 在游戏文件副本中验证了字段 / 类型改名及单例地址变化后的自动适配，新增角色读取配置也通过核验；原游戏文件未修改。
