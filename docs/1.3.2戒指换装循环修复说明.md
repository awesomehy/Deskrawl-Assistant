# 1.3.2 戒指换装循环修复

基于 v1.3.2，供本地验证；未推送分支、创建 PR 或公开 Release。

## 原因

游戏中“屠龙戒”在固定单体 Boss 场景提供 35% 攻速。旧预览只替换词条和宝石，保留当前已穿戴装备的条件层；因此卸下屠龙戒时没有移除攻速，穿上时也没有加回。真实脱敏回归复现 A→B 虚报 +922、B→A 虚报 +424，造成戒指 1 每两秒交替换装。

## 修复

从匹配 Deskrawl 1.0.2b 的本地资源提取 11 件装备、12 项可确定的固定／条件属性和转换特效，记录在现有 loot-item-ui.json。预览在替换词条后，比较完整穿戴组合的特效来源，移除旧装备特效并加入新装备特效；另一枚戒指仍提供的同一特效不会误删或重复加入。固定场景仍排除临时状态、技能触发和未适配的复杂效果，不进行完整战斗模拟。

读取端按元数据和 GameAssembly 哈希标注特效适配状态；未知构建不套用该表。tools/extract_equipment_comparison_effects.py 仅只读游戏资源；维护新构建时应在刷新 loot-item-ui.json 之后重新执行，不能根据中文效果描述猜数值。

## 验证

- 1065 项 Python 测试、83 项前端逻辑测试通过。
- 真实数值回归：穿 A 的固定战力 81372，穿 B 为 68119；A→B 为 -13253，B→A 为 +13253。与操作日志中的两种实际状态一致。
- 覆盖两个戒指槽位互换、保留另一枚戒指特效、自身比较为零、只升级一次后保持稳定，以及固定特效、条件特效、转换和未知构建保护。
- 当前游戏只读重算通过，确认适配哈希匹配；未调用换装、锁定、出售或启动托管。
- 修复版实机托管是否停止循环由用户确认。使用前退出旧助手，保留桌面的 runtime-paths.json 即可沿用原配置与 D:\Download 缓存。
