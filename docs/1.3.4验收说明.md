# 1.3.4 验收说明

适配基准：Deskrawl 1.0.3 / Steam build 25973417，Windows x64。

## 功能与修复

- 更新背包、仓库、马车、角色、掉落计划、成长与托管动作的版本绑定及兼容性基线。按游戏新结构读取属性，新增“固定伤害减免”，更新武僧天赋及相关资源。
- 物品目录更新为 588 项、装备名称 223 项，新增 12 件传说装备和 2 件神圣装备。补全炼血者之履、荣耀角斗士头盔、铁面暴君之盔、薛定谔之戒、风暴守护项链、收割者护肩的动态效果说明，在筛选规则、背包仓库及已穿戴装备预览共用。
- 修复神秘商人购买被背包常驻药水阻塞：保留药水并按实际空格批量购买；待处理装备仍需先筛选、锁定、收纳或出售／分解，不把常驻消耗品当作未整理的新装备。
- 商人定位改为有限等待和状态复核，避免重复打开对话；超时提供明确原因，结果不明的购买不重复提交。
- 合入 PR #7 中与双戒指反复互换相关的修复：换装比较先移除被替换装备的条件属性效果再计算新装备，避免重复叠加造成来回换装；未合入该 PR 的其他内容。

## 配置与保护

保留已有筛选规则、托管、换装、成长、购买及整理设置。神圣／黑雾装备、套装／宏伟符文继续禁止出售或分解；神圣装备禁止自动穿戴。观星默认关闭，程序不会自动连接游戏或启动托管。暂停开发的微信远控不包含入口、接口或组件。

## 验证范围

完整 Python 与前端回归、隔离单文件程序启动、内置资源及配置保存重启验证的最终结果见本版 Release。

游戏 1.0.3 已完成只读连接验证，玩家已完成开发版简单测试并确认可发布。动作入口已逐项静态核验并经过离线回归；不将这次简单测试表述为全部职业、全部玩法的完整实机验证。详细基线见 [游戏 1.0.3 兼容性验证](游戏1.0.3兼容性验证.md)。

GitHub Release 仅提供 `Deskrawl-Assistant-v1.3.4.exe`。
