# 1.3.6 验收说明

适配基准：Deskrawl 1.0.3 / Steam build 25973417，Windows x64。本次以正式 1.3.5 源码为基线，仅合入以下五项修复。

## 修复内容

1. **重复刷图漏计数**：读取游戏累计通关计数，缓存独立核验的通关记录，计数不再受完整物品扫描、马车新增物品或在途操作等待影响。快速复刷、关卡切换和暂时读取失败后可依据已确认记录补计；同一次胜利的多种证据去重。失败、未通关退出和观星跳过不计数，启动或恢复时不补计此前非托管期间的场次，两张地图分别计数。
2. **马车卸货重复监控**：统一无 UID 掉落在地面、马车中的身份表示；主城搬运和暂时空清单不当作新增获得，已在战斗中记录的高价值掉落不因卸货再次记录。
3. **监控错误关联最后一局**：只在稳定战斗场景且关卡身份匹配时关联掉落计划。主城、传送和旧结算缓存不用于绑定新观测物品；来源不能确认时保留未关联记录，不把金条等额外物品归到最后一局。本次修复不改写已有监控 JSON，也不改变观星使用当前掉落计划的判定方式。
4. **金条预览缺少图标**：背包、仓库共用完整物品目录，补齐金条图标与效果描述。
5. **缰绳名称缺失**：当前资源中全部 66 种缰绳使用游戏中文名称、图标与解锁效果。累计掉落已缓存的英文 ID 随刷新更新名称，获得、出售和存入数量不变。

## 发布范围与配置

保留 1.3.5 已开放功能、用户规则及本地配置。没有增加拍卖行上传、Steam 自动出售、多开或远控组件；网站项目不在本次发布范围内。游戏原生动作校验与已验证能力列表沿用正式 1.3.5。

## 验证范围

1459 项后端与 118 项前端测试通过；单文件隔离窗体启动、设置保存重启、显式测试入口及源码与包内容核对通过。测试使用独立用户目录和本地统计回执服务。本次不连接或操作正在运行的游戏，不将离线回归表述为全部场景的实机验证。
