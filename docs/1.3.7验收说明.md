# 1.3.7 验收说明

适配基准：Deskrawl 1.0.3 / Steam build 25973417，Windows x64。本次以正式 1.3.6 源码为基线，仅修复马车收取后的空编号校验。

## 问题与修复

马车读取将无独立编号物品的编号规范为 `""`，背包读取空指针时返回 `None`。1.3.6 收取后的回读校验直接比较两者，导致宝石等物品已经进入背包，仍误报“马车收取后物品回读不一致，已停止自动整理”。

本次仅在收取后的比较中统一空编号；名称、数量、目标槽位和非空唯一编号仍需匹配。保留收取原子事务、写后回读、在途操作保护、搬运日志及监控去重，不重复提交收取。

## 回归与发布范围

覆盖空编号双向表示、跨栈宝石收取、非空编号匹配和不匹配、错误名称/数量/槽位/缺失物品，以及已提交回执在后续读取失败时保留。1463 项 Python 与 118 项前端测试通过；单文件隔离窗体启动、设置保存重启、显式测试入口及源码与包内容核对通过。测试使用独立用户目录和本地统计回执服务。

沿用 1.3.6 的已开放功能与用户本地配置。不包含拍卖行上传、Steam 自动出售、多开、远控或网站改动，不包含个人规则、日志和掉落留档。本轮不连接或操作正在运行的游戏，不将离线验证表述为实机收取测试。

GitHub Release 提供 `Deskrawl-Assistant-v1.3.7.exe`。
