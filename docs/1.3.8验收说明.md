# 1.3.8 验收说明

适配基准：Deskrawl 1.0.3 / Steam build 25973417，Windows x64。以正式 1.3.7 源码为基线，本版发布以下四项修改。

## 修复范围

1. **神话裂隙观星**：掉落读取将原始裂隙地图转换为包含层数的逻辑关卡标识，同时保留原始计划数据。要求当前场景、层数、世界难度与本局身份一致；不匹配时等待重新核验，避免将旧计划判为无目标奖励。
2. **观星回城恢复**：只有在稳定战斗场景且明确不存在传送、存档或在途请求时，才确认上次回城已被取消；连续三次确认取消后完成当前局，下一局恢复筛选。不放宽未知状态及提交后回执保护。
3. **死亡等待复活**：不因死亡单独发起回城或开始回城计时；等待原生复活，再重新判断当前关卡。失败和未通关退出不计成功局数，同局复活后成功仍只计一次，自动推图不因死亡立即退图。
4. **职业词条池**：按游戏 1.0.3 原生随机主词条的职业排除规则，为战士、法师、猎人、武僧提供独立筛选视图。副词条仍使用实际公共池；已有跨职业规则完整保留，其他职业的已选词条显示标记。只调整传说随机词条的编辑候选，不改神圣固定词条、掉落判定或仓库保护。

## 验证

1478 项 Python 与 124 项前端测试通过，覆盖裂隙身份对应、回城取消和在途保护、死亡复活计数、四职业各部位词条池及旧规则保存。单文件隔离窗体启动、显式测试入口、设置保存重启及源码与包内容核对通过。

验证使用独立用户目录和本机统计回执服务；本轮不连接或操作正在运行的游戏。没有把其他尚缺现场证据的计数、黑屏、商人等待等反馈宣称为已修复，也不认定武僧冲锋必然是回城中断的原因。

保留 1.3.7 的本地规则、设置及已开放功能。观星、合成默认关闭，不自动连接游戏或开启托管。发布不包含拍卖行上传、Steam 自动出售、多开、远控、网站代码，以及个人配置、日志和掉落留档。

GitHub Release 提供 `Deskrawl-Assistant-v1.3.8.exe`。
