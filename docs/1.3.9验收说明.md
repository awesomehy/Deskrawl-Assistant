# 1.3.9 验收说明

适配基准：Deskrawl 1.0.3 / Steam build 25973417，Windows x64。以正式 1.3.8 为基线，本版增加托管断线自动重连。

## 功能与使用

- 托管状态中新增“断线自动重连”和在线角色列表序号，从 1 开始计数。新旧用户默认关闭，保存托管设置后生效；所选项必须是当前托管的在线角色。
- 仅在托管运行时，检测到明确掉线提示才自动确认弹窗、切换在线列表、选择指定角色并调用游戏原生开始操作。
- 对明确的“无法连接服务器”提示自动确认并间隔重试。登录请求至少间隔 30 秒，选角等操作间隔 5 秒；其他弹窗等待手动处理。
- 进入游戏后核对原角色身份及完整背包数据，再继续原托管流程，保留累计掉落和轮刷计数。
- 空角色、序号越界、角色不符或 10 分钟未恢复会暂停并保留统计。暂停、停止或关闭此设置后不再继续登录。
- 合成、出售及购买等已提交但结果不明的物品操作继续核验，不因重新登录而重复提交。

## 验证

1503 项 Python 与 128 项前端测试通过。单文件隔离窗体启动、显式测试入口、重连开关及角色序号保存重启、源码与包内容核对通过。打包验证使用独立用户目录和本机统计回执服务，不连接或操作正在运行的游戏。

已在实际掉线现场验证：确认掉线提示，处理连接失败提示，重新选择原在线角色并进入主城；只读核对角色身份及完整背包和仓库数据。未开展长时间断网或多账号实机测试；取消重连、角色保护、旧配置迁移和计数保留由自动测试覆盖。

保留 1.3.8 的已开放功能、用户规则及本地配置。观星、合成和断线重连默认关闭；启动助手不自动连接游戏或开启托管。发布不包含拍卖行上传、Steam 自动出售、多开、远控、网站代码，以及个人配置、日志和掉落留档。

GitHub Release 提供 `Deskrawl-Assistant-v1.3.9.exe`。
