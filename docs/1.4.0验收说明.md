# 1.4.0 验收说明

适配基准：Deskrawl 1.0.3 / Steam build 25973417，Windows x64。以正式 1.3.9 为基线，本版修复托管流程的状态恢复与商人留包物品处理。

## 本次更新

- 修复优秀、稀有缰绳留在背包时阻塞神秘商人购买的问题；保留缰绳并按实际占格计算购买容量，传说缰绳继续按规则入库。
- 修复进图前“角色、场景或掉落正在变化”被误判为普通失败并停止托管的问题，重新读取后继续判断；已核验的通关记录继续保留。
- 搬运写入前“验证耗时异常，未移动物品”改为等待后重新读取与规划，保留原有 1 秒保护；持续异常时暂停并保留统计。
- 商人购买前遇到无法完成整理的物品时，明确提示物品名称并暂停，避免反复尝试购买；已提交而结果不明的操作仍不重复执行。
- 保留 1.3.9 的已开放功能、用户规则及本地配置。

## 验证与边界

1512 项 Python 与 128 项前端测试通过。单文件隔离窗体启动、显式测试入口、设置保存重启、源码与包内容核对通过。打包验证使用独立用户目录和本机统计回执服务，不连接或操作正在运行的游戏。

回归覆盖优秀／稀有缰绳与开光石留包时连续购买、买满背包后的整理与续购、传说缰绳先入库、满包限制，以及未知物品明确暂停。搬运超时用模拟内存验证未写入物品、恢复游戏进程并能在下一次正常搬运；托管用例验证等待退避、重新规划及状态变化后恢复进图。结果不明的已提交操作仍停止重复执行。

本轮未在玩家的故障现场实机复测。关闭显示器后退出、长时间挂机停止、连接期间资源文件增减三类反馈尚未确认根因，不列为本版已修复；游戏文件兼容性保护继续保留。

旧版规则与配置继续使用。观星、合成和断线重连默认关闭；启动助手不自动连接游戏或开启托管。发布不包含拍卖行上传、Steam 自动出售、多开、远控、网站代码，以及个人配置、日志和掉落留档。

GitHub Release 提供 `Deskrawl-Assistant-v1.4.0.exe`。
