# 1.4.1 验收说明

适配基准：Deskrawl 1.0.3 / Steam build 25973417，Windows x64。以正式 1.4.0 为基线，本版改善马车收取、在线同步等待恢复与连接权限诊断。

## 本次更新

- 修复马车收取前“容器或唯一编号发生变化，未收取”等校验失败直接停止托管的问题；尚未写入时等待后重新读取与规划，不沿用旧物品选择。
- 马车收取前核验耗时异常时改为等待重试，保留原有 1 秒校验保护；收取后结果不一致、回滚失败等情况仍停止，避免重复操作。
- 改善在线同步等待恢复：尚未提交的回城、进图或难度切换请求，不再仅因等待超过两分钟就暂停；同步恢复后重新读取状态并继续托管，已提交或中断的传送仍保留超时保护。
- 连接游戏被拒绝访问时补充权限诊断；检测到游戏与助手的管理员权限差异时明确提示，否则提供启动账户、权限及安全软件拦截记录的排查指引。
- 保留 1.4.0 的已开放功能、用户规则及本地配置。

## 验证与边界

128 项前端测试通过；版本调整后补验的 34 项打包路径、更新及窗体测试通过。单文件隔离窗体启动、显式测试入口、设置保存重启、源码与包内容核对通过。打包验证使用独立用户目录和本机统计回执服务，不连接或操作正在运行的游戏。

1530 项 Python 测试通过；新增用例覆盖权限诊断成功与失败、马车收取前快照变化与核验超时、未写入时重新规划、写入后异常回滚，以及在线请求等待超过两分钟后恢复、原生游戏已回城时重新规划、手动停止和已提交传送的保护边界。Windows 权限查询接口已在本机进程上完成只读检查。

本轮未在玩家的故障现场实机复测。拒绝访问的具体环境原因、游戏在线请求长期未完成的根因仍待日志确认，不宣称已解决所有权限或网络问题；在线请求一直未完成时继续等待，不清空游戏请求计数或强制提交切换。

旧版规则与配置继续使用。观星、合成和断线重连默认关闭；启动助手不自动连接游戏或开启托管。发布不包含拍卖行上传、Steam 自动出售、多开、远控、网站代码，以及个人配置、日志和掉落留档。

GitHub Release 提供 `Deskrawl-Assistant-v1.4.1.exe`。
