# 1.4.2 验收说明

适配基准：Deskrawl 1.0.3 / Steam build 25973417，Windows x64。以正式 1.4.1 为基线，开放交易所上传与 Steam 市场出售。

## 本次更新

- 新增托管交易所上传与 Steam 市场出售，默认关闭；按商品类别授权，并支持具体商品强制保留。
- 背包与仓库新增手动批量“上架交易所”，可勾选同时上架 Steam 市场；仅在已确认主城且托管及其他物品操作未运行时可执行。
- Steam 官方窗口登录后自动保存本机加密凭证并关窗，重新打开助手可恢复登录；出售须依次满足交易所上传开启、Steam 登录有效及游戏账号一致。
- 支持最低在售价或最高求购价，均按买方支付的含手续费总价，使用实际 Steam 钱包币种；手机或邮件确认仍由玩家完成。
- 上传统一忽略锁定状态；保留穿戴、绑定、强化、有孔、身份核验和游戏原生交易限制。结果不明时保留在途记录并核验，不重复提交。
- 修复早期开发版退休字段导致整份托管配置加载失败的问题；保留已有筛选、换装、成长、刷图、商人、合成及收纳设置。

## 使用与边界

托管的允许类别包括神圣装备、黑雾装备、符文套装、宏伟符文、传说缰绳、开光石、金条；默认全不选。强制保留商品按具体种类设置并优先于类别授权。无独立实例编号的金条、开光石等堆叠材料暂不上传，界面注明原因；不伪造身份或推测扣除数量。

自动出售是上传的后续步骤，取消上传会同时取消出售。未登录时点击出售会提示前往托管页绑定 Steam。仅上传不需要助手中的 Steam 登录；上传与出售都需要游戏自身的在线交易许可。只有准确匹配本工具已确认上传的新增 Steam 资产才会提交卖单，不自动接管原有库存。达到上传名额、无背包空位、缺少报价、市场受限或结果未确认时，不盲目重发。

手动批量以本次选中商品为准，不依赖托管类别与保留名单；选中已锁定物品也会参与上传。战斗、死亡、传送、在线同步中、场景状态过期或不可读时禁止手动操作，确认页及逐件提交前再次复核。

凭证使用当前 Windows 用户的 DPAPI 加密，仅在本机保存；更换电脑或 Windows 用户需重新登录。Steam 要求手机或邮件确认时由用户完成；接受卖单或挂牌并不等于成交。

1.4.1 配置可直接升级，新增开关默认关闭。早期开发版的退休字段自动迁移，旧单品授权不会自动扩大为整个类别。回退 1.4.1 前须恢复旧配置备份或转换新增的上架配置。

## 验证范围

1784 项 Python 测试、179 项前端测试通过；正式单文件窗体和显式测试入口均通过隔离启动、配置保存重启验证。交易模块与页面资源内置、正式动作授权、源码与包内容核对通过。验证使用独立数据目录与本机统计回执服务，不连接或操作正在运行的游戏，不向公网上报测试身份。

2026-10-25 经用户授权，一枚宏伟符文完成真实游戏上传、原生回执核对与 Steam 新增资产匹配，并提交最低在售价卖单；用户在 Steam 代售列表确认挂牌。该结果不代表已经成交，也不代表其他品类、最高求购价和手动批量均完成实机交易。本轮发布验证不追加真实出售，不操作正在运行的游戏。

多开、远控及网站代码不包含在本次发布中；个人规则、登录凭证、背包快照、交易日志及掉落留档不随程序分发。详细流程见 [拍卖行与 Steam 市场验收说明](拍卖行与Steam市场验收说明.md)。
