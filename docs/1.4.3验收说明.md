# 1.4.3 验收说明

适配基准：Deskrawl 1.0.3 / Steam build 25973417，Windows x64。以正式 1.4.2 为基线，本次仅修复神秘商人补货确认与托管恢复流程。

## 本次更新

- 修复神秘商人补货原生调用已完成、库存回读延迟时，托管直接停止的问题；改为保留原请求并继续核验，不重复补货或购买。
- 补货后额外核验 120 秒，若游戏状态稳定但所需库存仍未恢复，先按原规则整理已购装备，再跳过本轮消费、继续其他托管流程；库存恢复后可重新参与消费判断。
- 游戏状态持续不可读、角色或灵魂碎片变化时仍暂停核验，保留统计；购买结果未确认时的防重复保护继续生效。
- 补充补货前后库存、碎片及核验耗时日志，便于定位延迟问题。

## 行为与兼容性

仅当原生补货调用已经完成、但短时间未读到所需库存时，转入后续核验；不会把调用完成当作补货成功。原请求未核验前不再提交补货或购买。若库存持续为空但游戏状态稳定，先关闭商人并按既有规则筛选、锁定、存放或处置已购装备，再继续其他托管流程；不因碎片仍高于阈值而反复回城补货。

若游戏状态持续不稳定，或核验期间角色、灵魂碎片变化，仍保护性暂停并保留统计。暂停后继续时重新核验原请求；主动停止不再开启新购买循环。购买及其他消耗动作的未确认保护不放宽。

1.4.2 的规则、托管预设、商人购买比例、收纳及 Steam 配置可直接沿用，本次不改变配置结构。交易所上传与 Steam 市场出售功能和限制见 [拍卖行与 Steam 市场验收说明](拍卖行与Steam市场验收说明.md)。

## 验证范围

1797 项 Python 测试、179 项前端测试通过；正式单文件窗体和显式测试入口均通过隔离启动、配置保存重启验证。补货等待与恢复回归、正式动作授权、源码与包内容核对通过。验证使用独立数据目录与本机统计回执服务，不连接或操作正在运行的游戏，不向公网上报测试身份。

测试覆盖延迟回执、持续空库存、在线同步等待、角色／余额变化、暂停继续、主动停止，以及先保护已购黑雾装备、处置未命中装备再恢复刷图。概率或延迟测试使用模拟状态，不为验证而真实购买或补货。

本轮发布验证不操作正在运行的游戏和助手。多开、远控及网站代码不包含在发布中；个人配置、凭证、日志和掉落留档不随程序分发。
