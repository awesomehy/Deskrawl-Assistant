# 1.4.4 验收说明

适配基准：Deskrawl 1.0.3 / Steam build 25973417，Windows x64。以正式 1.4.3 为基线，本次修复马车收取、自动合成恢复、目录核验与更新检查。

## 本次更新

- 马车正在收集或收取前状态变化时，等待下一轮完整读取并重新规划，避免把尚未写入的暂态当作失败而停止托管。
- 宝石、符文合成原生调用已完成但经济结果延迟时，保留原请求并继续核验材料、产物及序号，不重复提交合成。
- 合成结果确认后单独恢复魔盒动画与助手选择的材料清理；清理暂不可用时仅重试清理，不再次消耗材料，也不清空玩家新选择的材料。
- 同一助手内暂停、继续或停止后重新启动，先处理原合成核验；持续未确认时暂停并保留统计，继续时重新核验原操作。合成产物及材料搬运不计为新增掉落。
- 按实际文件系统身份比较游戏进程与模块目录，兼容路径别名；不同目录或无法核验时仍拒绝连接。
- GitHub 更新检查与下载使用 Windows 原生证书验证；保留域名、证书链、HTTPS 来源及下载校验。检查失败后按 1、3、5 分钟重试，之后恢复每小时检查；错误提示区分网络、DNS、证书、限流及安装写入问题，日志只保留类型与错误码。

## 行为与兼容性

仅马车收取前明确的暂态进入等待重试；收取后结果不一致、回滚失败等情况仍停止并提示检查，不把所有收取异常当作可重试。

只有原生合成批次明确完成，才进入材料与产物回执恢复。原生执行超时或部分执行仍保留不确定状态保护。连续 120 秒未确认回执或完成魔盒清理时暂停；同一助手内继续可核验原操作，切换角色或连接时先暂停核验。核验记录不承诺跨助手退出保存；结果不明时应先检查原角色背包，避免反复重开合成。

1.4.3 的规则、托管预设、商人比例、合成上限与排除列表、收纳及 Steam 配置可直接沿用，本次不改变配置结构。多开、远控与网站不纳入发布。

## 验证范围

1836 项 Python 测试、179 项前端测试通过；正式单文件窗体和显式测试入口通过隔离启动、配置保存重启验证。冻结程序实际读取 GitHub HTTPS 更新信息成功；原生证书组件、源码与包内容核对通过。

回归覆盖马车收集暂态、收取后不一致、合成回执延迟、概率产物、错误序号、角色变化、魔盒清理重试、暂停与停止恢复及掉落统计。证书测试确认过期、域名不匹配、自签名证书仍被拒绝。本轮不为验证而执行真实收取、合成、购买或出售；隔离启动使用本机统计回执服务，不向公网上报测试身份。

GitHub Release 提供 `Deskrawl-Assistant-v1.4.4.exe`。个人配置、凭证、日志和掉落留档不随程序分发。
