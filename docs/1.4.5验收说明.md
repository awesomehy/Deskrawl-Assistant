# 1.4.5 验收说明

适配基准：Deskrawl 1.0.3 / Steam build 25973417，Windows x64。以正式 1.4.4 为基线，本次修复托管符文连续合成被魔盒残留材料引用阻塞的问题。

## 本次更新

- 上一轮符文已消耗且产物回执确认后，结束结果动画并调用游戏原生清槽方法，清空材料槽引用；不再将结束动画误当作清槽完成。
- 清理后重新读取材料槽、动画及窗口状态。清理未完成时保留原核验，仅重试界面清理，不重复提交合成或消耗材料。
- 再次启动遇到旧版遗留的隐藏魔盒引用时，仅在动画与在线请求均空闲、背包完整读取、全部引用均为已不在背包及物品注册表中的符文时，允许原生重新打开并清理。
- 玩家仍在背包或仓库中的选材、可见魔盒中的选材、身份不明的材料均保留；合成后玩家新选择的材料不会被助手清空。

## 行为与兼容性

不改变合成品质上限、跳过名单、锁定与穿戴保护，也不改变材料配方、数量、概率或费用。沿用 1.4.4 的结果核验和防重复提交保护；合成产物及材料搬运继续不计入新增掉落。

1.4.4 的装备规则、托管预设、合成上限与排除列表、收纳及 Steam 配置直接沿用。本次不改变配置结构；自动合成对新用户仍默认关闭。

## 验证范围

修复开发版已由用户在本机实测并反馈通过。自动回归覆盖连续两轮合成、旧版隐藏残留、仍存在的背包及仓库材料、混合或未知身份选材、清理回读未完成、清理失败恢复与防重复消耗。新增原生清槽方法已对当前游戏进程进行只读构建与指令校验。

1845 项 Python 测试、179 项前端测试通过；正式单文件窗体和显式测试入口通过隔离启动、配置保存重启验证。冻结程序实际读取 GitHub HTTPS 更新信息成功；原生证书组件、源码与包内容核对通过。

GitHub Release 提供 `Deskrawl-Assistant-v1.4.5.exe`。个人配置、凭证、日志和掉落留档不随程序分发。
