# 1.5.0 验收说明

目标：Deskrawl **1.1.0 / Steam build 26310087**，Windows x64。验证日期：2026-10-30。

## 游戏 1.1.0 适配

- 更新背包、仓库、马车、角色、关卡、掉落预览、成长、神秘商人、合成、交易所和断线重连接口，保留结构、资源、原生动作指纹与结果核验。
- 同步 602 项物品的名称、图标和效果；补充新增仆从装备、猎人装备、世界首领奖励、缰绳、宝箱、神话代币以及成长节点资源。
- 仆从成长、继承槽位与技能提供只读数据接口，不执行自动培养、继承技能分配或代币兑换。仆从装备与角色装备分开，不能作为角色自动换装候选。
- 游戏详细掉落日志改为有界队列后，按稳定记录索引读取并去重；快照变化时不提前更新读取游标。
- 宝石堆叠上限与灵魂碎片容量读取当前游戏数据；宝石、符文合成沿用已有配置，按新版在线配方核验材料、金币费用及产物。

## 仆从装备

- 背包与仓库增加仆从装备筛选、名称、图标和详细展示。
- 回城整理增加独立处置方式与存放页；旧配置默认补为入库，沿用原装备仓库页，不继承旧装备的出售或分解策略。已锁定和黑雾仆从装备继续保护，目的地满时保留背包并暂停等待。
- 累计掉落单独展示仆从装备及获得、出售、分解、入库数量。
- 交易所上传和 Steam 出售增加“仆从装备（可交易）”类别，默认不选。原有黑雾装备类别不扩大到仆从装备，强制保留名单优先，实际可交易状态仍以游戏和 Steam 核验为准。

## 南瓜王与宝箱

- 普通、噩梦、炼狱难度下可选择南瓜王重复刷图，支持单图复刷、双图轮换、成功通关计数与观星，自动推图不将活动首领插入主线路线。
- 入场前读取实际解锁、活动时间、服务器时钟和三档共享的每日入场次数，界面显示剩余次数及不可进入原因。次数耗尽或活动关闭时，先完成当前局奖励收取和回城整理，再暂停并保留统计。
- 观星退出同样消耗游戏入场次数；最后一次入场不提前放弃。
- 修复南瓜王宝箱预览已识别、背包分类和原生开箱白名单仍只支持旧宝箱的遗漏。普通、噩梦、炼狱宝箱按资源中的开箱效果识别，回城整理后自动开启未锁定宝箱并重新扫描奖励；皇家宝箱同样遵循资源核验。
- 开箱提交前核对实际 `ItemData.Effect == OpenChest`，不因名字含有“宝箱”或属于消耗品就直接使用；锁定、身份不明或背包无空位时不自动开启。

## 从 1.4.6 直接升级

- 1.4.6 更新器按数字比较三段版本号，允许直接选择 `v1.5.0`；发布资产保持 `Deskrawl-Assistant-v1.5.0.exe`，Windows 产品版本为 `1.5.0.0`，继续核验大小、SHA256 与正式 Release 来源。
- 使用相同的本机用户数据路径。原有筛选规则、托管与整理设置、关卡轮换、合成上限、跳过名单、市场显示币种、日志和留档继续保留。
- 用 1.4.6 源码生成非默认旧配置，验证新版加载和保存后保留原有字段，仅补齐仆从装备默认入库及原装备存放页；不增加交易所或 Steam 出售授权。
- Steam 凭证继续按当前 Windows 用户使用原有 DPAPI 存储；有效性仍由 Steam 验证，更新不会替失效凭证重新授权。
- 升级前保存设置。手动升级应退出旧助手，再启动新 exe；回退旧版前保留对应配置备份。发布前不将验证用的模拟 Release 写入真实更新服务器，也不替换用户正在运行的助手。

## 验证记录

- 完整回归：1898 项 Python 测试、185 项 Node 界面测试全部通过。
- 正式单文件构建完成；隔离中文及空格目录中验证窗口加载、资源读取、设置保存、退出重开及重复启动复用，未连接真实游戏或向公网统计服务发送测试身份。
- 用真实 1.4.6 源码生成旧配置，验证新版加载时不改原文件、保存及重新加载保持原偏好；用 1.4.6 更新器校验实际 1.5.0 EXE 的 Windows x64 格式、产品版本及模拟 Release 元数据。正式线上升级仍需发布后由 GitHub 提供资产。
- 首次单文件检查发现构建运行时的 SSL 模块依赖一份额外公共证书策略文件，已补齐打包资源并重打包；没有关闭 HTTPS 证书校验，重测未再出现启动错误。
- 此前仆从装备和南瓜王刷图开发版已由用户测试并确认通过；后补的南瓜王宝箱流程以资源、原生入口审查与离线回归验证，不记录为实机消耗宝箱验收。

接口变更、文件指纹与只读实机范围见[游戏 1.1.0 兼容性验证](游戏1.1.0兼容性验证.md)。个人规则、凭证、快照、日志数据库和掉落留档不随程序分发。
