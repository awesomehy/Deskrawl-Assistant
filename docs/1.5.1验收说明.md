# 1.5.1 验收说明

目标：Deskrawl **1.1.0 / Steam build 26310087**，Windows x64。验证日期：2026-10-30。

## 南瓜王优先刷取

- 自动刷图中增加独立的“优先刷南瓜王”开关，新用户默认关闭；普通副本的推图或轮刷开关独立保留。
- 南瓜王支持普通、噩梦、炼狱及沿用启动时当前难度，显示游戏实际读取的每日共享入场次数。
- 主城整理完成后优先选择南瓜王；次数用尽、活动结束或尚未解锁时继续原副本配置。未开启原副本时等待重置或活动开放，状态尚未读全时等待读取，不凭未知状态消耗入场次数。
- 已经进入的南瓜王先完成本局奖励收取和整理；成功次数独立记录，不改变普通副本的轮换配额。
- 难度与次数位于设置左侧，开关在右上，与原副本刷图开关对齐；普通关卡下拉列表不再显示南瓜王。

## 仆从装备按品质整理

- 黑雾传说固定锁定入库，不提供出售或分解配置。
- 普通传说和稀有分别支持入库、出售或分解；共用独立的仆从装备仓库页，已锁定装备继续保护，满仓时留在背包并暂停等待。
- 执行出售或分解前重新核对实际品质与配置，避免设置变化后沿用旧处置。
- 既有交易所上传及 Steam 出售权限、强制保留名单继续独立核验，不由整理选项扩大权限。

## 观星与旧配置

- 观星刷本入口暂时隐藏，配置加载及保存时强制关闭旧观星开关，不再自动筛选并跳过关卡；历史奖励勾选继续保留。掉落预览和高价值掉落监控保留。
- 旧版重复刷图中配置的南瓜王迁移为独立开关及难度；保留其余普通副本。若原配置仅有南瓜王，迁移后仅开启南瓜王，不虚构普通副本目标。
- 仆从装备原统一处置分别迁移到普通传说和稀有，存放页沿用；更早配置没有仆从装备设置时，仍默认入库。
- 原筛选规则、其他托管设置、合成上限、符文跳过名单及同一 Windows 用户下有效的 Steam 登录凭证继续保留。回退前保留对应版本配置备份。
