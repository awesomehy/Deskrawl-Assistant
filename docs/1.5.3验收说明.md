# 1.5.3 验收说明

目标：Deskrawl **1.1.0 / Steam build 26310087**，Windows x64。验证日期：2026-10-31。

## 南瓜王最终结算恢复

- 修复每日次数耗尽后，游戏已经显示南瓜王结算界面，但助手继续等待本局结果的问题。
- 游戏在最终结算时可能清空当前计划引用；仅在南瓜王结算弹窗可见、场景稳定时，从同地图、同难度的已结束波次恢复本局核验依据。
- 要求当前地图对象、保留计划、全部波次完成状态一致且没有存活敌人；保留整个读取期间的变化检查，不将普通副本、旧弹窗、传送过程或死亡状态误认为成功。
- 确认本局后先收取奖励并完成回城整理，再继续原有自动推图或重复刷图；未开启原副本刷图时等待每日重置。
- 同一局重复读取只生成一次成功记录，南瓜王成功次数不占用普通副本轮换配额。

## 配置兼容

- 本次不增加或更改配置字段，沿用 1.5.2 的筛选规则、托管设置、整理分区、合成预设及有效 Steam 登录凭证。
- 1.5.2 可直接升级；既有旧版本配置迁移继续保留，不需要重设南瓜王或常规刷图目标。
- 观星入口继续隐藏并停用，不新增多开或远控入口。
