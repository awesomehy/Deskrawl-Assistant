# 1.5.4 验收说明

目标：Deskrawl **1.1.0 / Steam build 26310087**，Windows x64。验证日期：2026-10-31。

## 南瓜王结算后优先复刷

- 结算后不再固定每局回城，剩余入场次数足够时先收完 Boss 地面掉落，再继续复刷。
- 复用回城前的奖励保护：金币优先、装备先于宝箱拾取；地面必须完整读取，并连续核验清空、结算稳定后才允许复刷。满包且无法腾位时暂停并保留现场，不带着未拾取奖励切图。
- 调用游戏结算窗口的原生复刷按钮方法，先关闭结算窗口并停止其倒计时，再发起原生复刷；保留原生忙状态与材料检查。
- 提交前重新读取当前局、每日次数、背包空格、宝箱与碎片消费条件；原生已开始下一局时不重复提交。
- 次数耗尽、活动关闭、宝箱达到 20 个、背包空格低于门槛、触发商人消费或回城后停止时，按既有回城保护流程收取奖励并整理。
- 沿用南瓜王次数耗尽后的原副本续刷、通关去重与独立计数；普通副本流程不调整。

## 配置兼容

- 不增加或修改配置字段，1.5.3 可直接升级；已有筛选规则、托管预设、分区、合成及有效 Steam 登录凭证继续保留。
- 旧版配置迁移、观星停用状态和交易权限默认值保持原状。
- 不增加多开、远控或其他预研功能入口。

- 对照已验证游戏基准 DLL 与元数据，核验原生复刷按钮、结算窗口实例与事件布局；未修改游戏文件或执行实机复刷。
