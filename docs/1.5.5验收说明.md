# 1.5.5 验收说明

目标：Deskrawl **1.1.0a / Steam build 26337088**，Windows x64。验证日期：2026-10-31。

## 游戏版本适配

- 刷新背包、仓库、马车、仆从、关卡、掉落预览、成长、商人、合成、交易所及重连使用的类型布局、混淆名称、原生入口和资源指纹。
- 新版 `SaveSystem` 新增布尔字段后，物品操作标志由 `+192` 移至 `+193`，在线保存标志由 `+193` 移至 `+194`；分别更新读取，保留原有校验与在途操作保护。
- 核对 57 个原生方法、6 个导出入口、5 个未初始化类型令牌及相关单例，更新含 15522 个原生方法的兼容性基线。
- 资源语义比对未发现新增或移除物品，物品名称、效果、可交易属性、关卡、职业词条池及合成规则没有内容变化。

## 配置兼容

- 不增加或修改配置字段，1.5.4 可直接升级；已有筛选规则、托管预设、分区、合成及有效 Steam 登录凭证继续保留。
- 沿用既有旧版配置迁移，观星入口停用和交易权限默认值保持原状。
- 不增加多开、远控或仆从自动培养入口。

## 验证记录

- 1970 项 Python 回归与 193 项 Node 界面测试通过，包括新增的保存标志位置回归。
- 已连接真实 1.1.0a 游戏完成两轮主城只读核验，背包与仓库完整、角色及仆从装备、关卡解锁、南瓜王次数、马车状态、商人报价、宝石／符文配方与游戏累计统计均正常读取。
- 当前进程中 57 个原生方法及 6 个导出入口的代码前缀匹配，未安装分发器或执行游戏方法。
- 最终 Windows x64 单文件 exe 在隔离目录完成 WebView2 启动、保存与重启及 GitHub HTTPS 更新检查。主城实机只读核验使用相同适配代码；最终 exe 检查时游戏已退出，未重新连接。
- 使用真实 1.4.6、1.5.0、1.5.1、1.5.2、1.5.3、1.5.4 旧版代码生成配置，验证迁移、保存与重载；六版旧更新器均可发现并核验实际 1.5.5 exe。
- 当前主城未加载战斗技能控制器及副本掉落计划；战斗、结算与连续复刷待副本验收。实际购买、合成、搬运和上架未在此次执行。
- 发布包按既有白名单构建，不包含个人配置、快照、凭证或预研模块。
