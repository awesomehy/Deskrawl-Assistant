# 1.6.0 验收说明

目标：Deskrawl **1.1.0a / Steam build 26337088**，Windows x64。

## 助手设置

- 设置页面、受保护的保存接口、独立设置文件、Steam 社区加速、托盘、老板键、数据目录入口及分类重置完整接入同一发布源码。
- Steam 加速默认关闭，覆盖公开报价、独立登录窗口及托管市场请求，包括库存分页、行情、卖单提交、待手机确认／已挂牌记录核验；关闭后保留原通道。不修改系统代理、Hosts、DNS 或证书，保留 HTTPS 校验和限流退避，卖单写入不切线重试。
- 数字快捷键注册上排与小键盘两组，任一冲突或保存失败都回滚，保留旧设置；托盘退出释放注册和图标。
- 重置弹窗说明影响并默认取消；备份成功后才原子替换配置，运行任务时拒绝重置，清缓存不清 Cookie 或登录凭证。
- [详细说明](助手设置说明.md)。

## 仆从随机词条

- 按本地游戏原生生成逻辑合并仆从主副候选池，按职业过滤后形成一组随机词条；传说装备最多三条，固定效果不参与筛选。
- 新规则按至少命中 N 类判断；背包筛选、详情高亮、全中标记、自动锁定及回城整理共用规则结果。
- 可等价转换的旧单组配置可继续使用；旧主副双组继续保留原有 AND 语义，编辑器确认转换并保存后才使用新格式，未确认时不改写旧配置。
- 命中规则或黑雾仆从装备继续固定锁定入库；未命中处置与独立仓库页保留。

## 商人与交易所

- 按经过原生访问器核验的窗口真实显示状态确认商人开启与关闭，不使用无关托管标志代替。
- Steam 登录过期时只暂停市场出售，不阻塞游戏交易所上传；仍核验游戏物品身份和上传结果，失效的可选资产基线不会绑定到后续其他资产。
- 即使托管未启动，Steam 登录也每 30 秒后台核验；只有官方未登录／身份失效回执才判定过期，网络错误、限流与不可读页面仅等待重新核验。
- 明确过期时显示重新登录提示，自动取消并保存 Steam 出售开关，保留游戏交易所上传和其他配置；重新登录不自动恢复出售。
- 识别 Steam 官方登录凭证刷新跳转，顶部直接显示“登录凭证已过期，请重新登录”；不向跳转目标转发 Cookie，其他不支持的跳转不误判为过期。
- 待手机确认数量只使用 15 秒内的出售回执或卖单回读，不从历史日志恢复数量；读取失败立即隐藏，不将缺少记录视为允许重卖。托管未运行或关闭自动出售时仍继续只读核验已有卖单。

## Steam 登录

- 加速登录保留 Steam 原始 HTTPS 地址，补齐登录页面、二维码会话、认证轮询及手机确认后建立会话所需的官方请求；不向页面注入助手 JS 桥，不保存账号密码。
- 用户已完成真实 Steam 登录验收：手机确认后窗口自动关闭，后台核验登录与 CNY 钱包成功，凭证使用当前 Windows 用户的 DPAPI 保存；退出并重新打开助手后，有效凭证自动恢复并核验通过。
- 现场验收使用本次诊断构建，最终包沿用相同业务源码；最终 exe 另行执行隔离启动、归档模块及升级检查。本轮没有提交真实卖单，未确定此前两次手机确认后失败的具体原因，不将手机和电脑 IP 不同视为已确认根因。
- 原生隐藏窗口离线检查通过：独立代理、隐私缓存、Cookie 读取与关闭释放；原生请求处理检查通过：保留 HTTPS 来源、遵守无凭证请求、POST 仅发送一次且内容不变、会话建立诊断不记录 Cookie、令牌或用户标识。离线检查没有访问 Steam。

## 升级与分发

- 沿用现有数据目录和配置文件，新设置单独持久化；不自动启动托管或连接游戏。
- 多开、远控与观星入口继续隐藏；个人配置、日志、Cookie、Steam 凭证与本机诊断文件不随源码或 exe 分发。
- 完整 Python 回归 2178 项、JavaScript 回归 228 项通过；包含设置保存与回滚、托盘生命周期、双数字键注册、重置确认、仆从随机词条与旧规则兼容、商人窗口、交易所及 Steam 登录回归。
- 最终 exe 通过归档资源检查、中文及空格路径独立 WebView2 启动、托盘创建、真实 Profile 缓存清理、设置与随机词条规则保存重启；使用隔离数据目录和本地模拟统计服务，不操作用户游戏或配置。
- 使用真实 1.4.6 及 1.5.0–1.5.6 旧版代码生成配置，八版配置载入、保存、重载均通过，旧更新器可识别并校验 1.6.0 的实际 exe。
- 最终包检查没有连接游戏、启动托管或操作真实物品；设置、仆从功能和登录实测由用户此前验收，发布检查不替代真实交易验证。
- GitHub 实时更新检查此前遇到匿名 API 限流（HTTP 403），不记为在线检查通过；旧更新器识别实际 1.6.0 exe 与更新资产校验的离线检查已覆盖。
- GitHub 上传与 Release 发布等待 README 和更新文案确认。
