# v1.6.2 验收说明

验证日期：2026-11-12。适配 Deskrawl 1.1.11 / Steam build 26604532，Windows x64。

## 本次范围

- 更新游戏结构与动作入口，覆盖角色、仆从、背包、仓库、马车、关卡、掉落、商人、成长、合成、拍卖行及重连；详见 [游戏适配验证](游戏1.1.11兼容性验证.md)。
- 读取 60 格背包和最多 8 页仓库，分别核验两份 DLC 授权；旧分区不自动扩展到新页。
- 更新 674 个物品预览资源、240 个装备筛选条目及 283 个宝石／符文预览条目。远古神圣保留独立读取身份与强制保护，不新增神圣装备筛选规则。
- 新七阶宝石上限可选，旧合成上限原值保留。英雄宝箱、符文宝箱使用既有开箱流程，符文宝箱不参与符文合成。
- 宝箱达到 30 个（含）回城；满包有可开启宝箱时仍优先腾位。神秘商人指令保留全部检查，校验表扩为 512 条且总分配保持 16 KiB。
- 本机 Steam 会话续期在独立、限时的辅助进程中执行，仅接受已核验的 Steam DLL；取得的凭证仍需核验账号和市场登录态。未知客户端版本回退正常登录。
- 金条和开光石使用独立的上传操作记录及原生扣料、服务器回执核验，不伪造物品 UID；未知材料仍拒绝上传。
- 界面重复数据避免重建，保留原有交互和配置方式。

## 离线回归与升级

- Python 2718 项、Node 277 项全量测试通过。
- 商人批量提交及最后一条校验不符、超容量拒绝、满背包分批开箱、药水占格、南瓜王回城条件均有针对性测试。
- 在独立临时目录验证 1.4.6、1.5.0—1.5.6、1.6.0、1.6.1 共 10 组配置的加载、保存和再次加载；与 1.6.1 的迁移结果一致。仓库页、合成品质上限及交易权限均不扩大。
- 使用 1.6.1 的更新器代码验证正式 exe 的 x64 格式、Windows 版本资源、大小和 SHA256，并确认可识别 1.6.2 的正式发行资产。无需中间版本。

## 打包验证边界

正式 exe 使用独立用户数据和本地统计回执服务验证，Steam 社区加速在该测试配置中显式关闭；不修改玩家配置、系统 hosts 或证书，不连接玩家游戏，不执行真实买卖、搬运或合成。

对打包文件核验应用模块、静态数据、图标、Windows 证书组件及项目许可；多开与远控原型、本地凭证、玩家配置及运行日志不随包分发。实机只读验证与离线模拟不能替代所有经济操作的在线验收。
