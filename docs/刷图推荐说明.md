# 当前角色刷图推荐

本功能自助手 v1.2.0 起提供，已验证 Deskrawl 1.0.2a，Steam build 25842017。独立打包程序无需 Python；v1.1.8 及更早的正式 Release 不包含本功能。

## 使用

1. 启动游戏并进入角色，打开助手，点击“连接游戏”。
2. 打开“刷图推荐”。默认比较60分钟内可以完成的刷图收益，顶部给出推荐地图，列表显示每轮预计经验、耗时、每小时经验、计划收益和完整通关次数。
3. 需要长期比较速度时切换“单位时间效率”。这个口径按持续刷图速度折算，预算不足一轮时也可查看；“完整通关收益”不把最后未完成的一轮当成完整奖励。
4. 保持助手连接并正常刷图。新场次开始、普通波、Boss波和完整结算会自动观察；无需逐关手工录入。中途连接的当前场次从下一轮开始用于完整计时。
5. 重开耗时默认「自动观测」：使用同图或同系列连续重开的观测中位数，没有样本时采用8秒。切换「手动指定」可填写进出图、结算和重开的额外耗时；包括手动填写8秒在内，均不会被观测值覆盖。长时间挂机休息不作为重开开销。

## 如何理解数字

- 关卡列表使用随机遭遇池及等级区间的经验期望。当前图“本轮计划总经验”来自已生成的刷怪计划，代表单次全清，不是60分钟收益。
- 经验奖励按游戏经验加成、难度和等级惩罚计算；有效规划经验已包含加成，直接累加，避免重复计算。
- 计划中的非正数奖励以当前角色等级和经验加成估计，途中升级或加成变化会重新计算；界面标明回退估计的来源。
- 时间按平均攻击伤害、大致攻击频率对比怪物总血量粗算，再加波次等待及重开开销。已有可读的普攻和周期触发用于估算均值；复杂技能循环不做精确仿真，以正常刷图耗时自动校准。首次预估不代表实测秒数。
- 校准按角色、配装和技能指纹隔离，普通波和Boss波分别计算；仅在相同系列内迁移阶段效率。升级会重新计算经验、伤害及候选，不直接沿用旧等级奖励均值。
- 已观察到失败会显示风险。足够的同图、同等级观测可计入失败保留经验及耗时；少量样本有波动，不提供未经验证的成功率保证。
- 地图准入检查前置通关、当前难度进度和入场道具。选择另一难度时，如果其进度未读取，显示“开放状态待确认”并不作为当前推荐。
- 已覆盖固定配置的常规地图。目录包含76图，其中71张常规地图可计算；其余特殊/神话图依赖动态参数，暂不参与排序。
- 满级巅峰累计经验读取仍有适配边界；无法核验经验累计时保留耗时观察，不虚构实测经验。旧“经验收益”页的手动录入仍可使用。

## 数据保存与更新

规则、日志和校准记录沿用助手的个人数据目录，推荐设置与观测保存在 `data/runtime/recommendations.sqlite3`。打包版默认使用 `%LOCALAPPDATA%\Deskrawl装备助手`；源码版使用项目目录。数据库和个人配置不包含在源码或打包资源中。

可通过 `DESKRAWL_ASSISTANT_DATA_DIR`、`DESKRAWL_ASSISTANT_CACHE_DIR` 指定数据和网页缓存目录。打包版也可在 exe 同目录的 `runtime-paths.json` 中设置绝对路径 `data_dir` 和 `cache_dir`，无需修改全局环境变量。

自动更新前会保存刷图推荐设置；“经验收益”中尚未结束或等待补录的采样需要先保存或取消，避免重启丢失计时。只读推荐观察在更新后从下一次完整刷图开始校准。

推荐通过外部读取实现，读取流程不调用游戏方法、不修改游戏内存或存档。既有装备锁定和整理功能仍按各自界面设置操作。

新增读取使用与装备功能相同的连接适配结果。字段改名和入口地址移动仅在布局、枚举、资源与原生逻辑完整核验通过后接受；重大变化仍需维护，不能通过关闭版本保护强行读取。
