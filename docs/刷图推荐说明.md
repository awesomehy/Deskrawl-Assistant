# 当前角色刷图推荐

适配 Deskrawl 1.0.2，Steam build 25817367。本功能位于本地分支 feature/experience-efficiency，安装后独立程序无需 Python。

## 使用

1. 启动游戏并进入角色，打开助手，点击“连接游戏”。
2. 打开“刷图推荐”。默认比较60分钟内可以完成的刷图收益，顶部给出推荐地图，列表显示每轮预计经验、耗时、每小时经验、计划收益和完整通关次数。
3. 需要长期比较速度时切换“单位时间效率”。这个口径按持续刷图速度折算，预算不足一轮时也可查看；“完整通关收益”不把最后未完成的一轮当成完整奖励。
4. 保持助手连接并正常刷图。新场次开始、普通波、Boss波和完整结算会自动观察；无需逐关手工录入。中途连接的当前场次从下一轮开始用于完整计时。
5. 默认额外流程开销为8秒，可以填写实际进出图、结算和重开耗时；保持默认时，已观察到的连续重开开销可替换默认值。长时间挂机休息不作为重开开销。

## 如何理解数字

- 关卡列表使用随机遭遇池及等级区间的经验期望。当前图“本轮计划总经验”来自已生成的刷怪计划，代表单次全清，不是60分钟收益。
- 经验奖励按游戏经验加成、难度和等级惩罚计算；有效规划经验已包含加成，直接累加，避免重复计算。
- 时间按平均攻击伤害、大致攻击频率对比怪物总血量粗算，再加波次等待及重开开销。已有可读的普攻和周期触发用于估算均值；复杂技能循环不做精确仿真，以正常刷图耗时自动校准。首次预估不代表实测秒数。
- 校准按角色、配装和技能指纹隔离，普通波和Boss波分别计算；仅在相同系列内迁移阶段效率。升级会重新计算经验、伤害及候选，不直接沿用旧等级奖励均值。
- 已观察到失败会显示风险。足够的同图、同等级观测可计入失败保留经验及耗时；少量样本有波动，不提供未经验证的成功率保证。
- 地图准入检查前置通关、当前难度进度和入场道具。选择另一难度时，如果其进度未读取，显示“开放状态待确认”并不作为当前推荐。
- 已覆盖固定配置的常规地图。目录包含76图，其中71张常规地图可计算；其余特殊/神话图依赖动态参数，暂不参与排序。
- 满级巅峰累计经验读取仍有适配边界；无法核验经验累计时保留耗时观察，不虚构实测经验。旧“经验收益”页的手动录入仍可使用。

## 本机文件

程序：D:\APP\Deskrawl-Assistant\Deskrawl-Assistant-v1.1.4-xp.exe

启动入口：D:\APP\Deskrawl-Assistant\启动刷图推荐助手.cmd

源码：D:\Download\Deskrawl-Assistant\source

下载、分析和浏览器缓存：D:\Download\Deskrawl-Assistant\cache

安装后的设置、日志、读数和校准数据库：D:\Download\Deskrawl-Assistant\user-data

本机版本通过只读外部读取实现推荐，读取流程不调用游戏方法、不修改游戏内存或存档。既有装备锁定和整理功能仍按各自界面设置操作。
