# 游戏 1.0.3 兼容性验证

验证日期：2026-10-16。适配 Deskrawl 1.0.3，Steam build **25973417**，Windows x64。

## 适配内容

- 更新背包、仓库、马车、角色、掉落计划、成长和托管动作的元数据绑定。混淆类改名使用已核验的实际类名，保留助手内部逻辑标识；字段、方法签名和版本校验继续生效。
- 按新版本布局调整角色属性转换、条件属性、状态缓存、技能等级和冷却数据读取。新增 `StatType.FinalDamageReduction = 66`（游戏名称为“固定伤害减免”），保留游戏原有数值上限及显示规则。
- 重新提取物品、词条、图标、效果描述和四职业天赋技能配置。物品预览目录从 574 项更新到 588 项，新增 12 件传说装备和 2 件神圣装备；物品本地化装备名共 223 项。
- 补全 6 件使用动态本地化效果的装备说明：炼血者之履、荣耀角斗士头盔、铁面暴君之盔、薛定谔之戒、风暴守护项链、收割者护肩。按资源中序列化参数及原生说明方法的格式生成文本，在筛选规则、物品预览及已穿戴装备详情共用；不将触发特效纳入战力估算。
- 更新连接时的兼容性基线，并验证后续仅混淆改名、字段改名或静态地址迁移的自动适配。资源、枚举、布局或原生逻辑发生其他变化时仍要求维护适配。

## 静态核验

核对 35 个托管动作入口的签名、原生代码和实际声明类，其中 33 个入口规范化指令不变，另外 2 个仅为新增事件字段引起的偏移变化。更新 44 个动作相关类型绑定，并重新核验游戏程序集、引擎和资源指纹。

自动适配验证使用复制的合成文件，将当前注册类和难度类再次改名、修改存档脏标记字段名并迁移单例地址；验证通过，未改写游戏安装文件。

独立源码副本（不含暂停开发的远控功能）验证结果：Python **1153 / 1153** 项通过，前端 Node **86 / 86** 项通过。新增回归覆盖属性 66、旧字段位置复用、混淆类名复用和后续再次改名的兼容性校验；物品目录检查覆盖新增图标和描述。

## 实机只读检查

连接正在运行的游戏，兼容性状态为已验证；背包 40 格、仓库 250 格读取完整，仓库 156 个占用格和 70 件装备没有读取问题。角色 70 级猎人、12 个装备部位、四类难度及成长配置读取正常；商人已解锁、10 个商品、灵魂碎片 105 / 3000 均可读取。原生游戏统计读取正常。

检查时角色在主城，掉落预览正确返回等待进入战斗关卡。本次未验证新版本战斗中的真实掉落计划，也未执行购买、出售、分解、加点、换装或切图；动作部分以静态核验及离线回归覆盖，不将其记为新版本实机操作验收。没有安装动作分发器或重启游戏／助手。
