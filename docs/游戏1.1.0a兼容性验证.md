# 游戏 1.1.0a 兼容性验证

验证日期：2026-10-31。目标：Deskrawl **1.1.0a / Steam build 26337088**，Windows x64。

先根据本机已经更新的游戏安装文件完成离线适配，再连接用户已经打开的游戏完成主城场景的只读验证。已确认真实连接及下列接口读取正常；没有安装动作分发器，没有执行购买、合成、搬运、上架或切图操作。

## 已完成的适配

- 更新背包、仓库、马车、仆从、关卡、掉落预览、统计、成长、商人、合成、拍卖行及重连使用的类型记录、混淆名称、字段元数据、原生地址和指纹。
- 对照实际元数据及原生代码确认：`SaveSystem` 在原有两个忙碌标志前新增一个布尔字段。物品操作标志由 `+192` 移至 `+193`，在线保存标志由 `+193` 移至 `+194`。同步修正托管动作、搬运、锁定、商人成长状态、拍卖行与合成的读取，保留两种标志原有的独立用途。
- 马车新增按装备部位分类的传说装备设置，导致其后部分字段移动；同步刷新完整类型结构。现有低品质处理统计读取的品质字典仍在 `+32`，不将新设置误当成原字段。
- 刷新 57 个原生动作入口的声明类型、签名、方法令牌、地址及代码前缀，核对 5 个未初始化类型令牌和相关单例、导出入口。保留现有功能开关及兼容保护，没有通过跳过检查接受新版本。
- 重新生成兼容性基线，覆盖 15522 个原生方法；刷新资源指纹及序列化对象编号，避免新版资源被判定为旧版本或读错对象。

## 资源与规则比对

与已发布的 1.1.0 适配数据比较，剔除序列化对象编号和来源指纹后：

- 物品名称、装备说明、图标关联、可交易目录没有内容变化，没有发现新增或移除物品。
- 77 个地图条目、66 个敌人条目的内容没有变化。
- 职业词条池、品质与部位枚举没有变化；另行核对了职业词条过滤的原生逻辑。
- 宝石 30 条升级配方、现有符文规则及成长配置没有变化。实际在线执行仍使用服务器返回的配方和费用。
- 游戏累计游玩时长、品质掉落计数和金币拾取统计的原生字段与读取逻辑核验通过；它们读取 `PlayerStatistics`，不把 `SaveData` 新字段导致的位置变化套用到这里。

## 离线验证

- Python **1970 项**测试通过，前端 Node **193 项**测试通过。
- 新增忙碌标志回归：新增私有字段不会被误认为在线保存；在线保存仍能阻止新操作；物品操作仍能阻止新的合成或拍卖行操作；在途结果核验可在忙碌时继续读取。
- 8 份类型配置共 118 项类型记录的完整字段与方法信息，均与当前安装文件逐项核对通过。

接口返回的 `native_verified` 包含既有版本的动作验收记录，不能据此宣称本次已执行并验证所有动作。此次只验证实际进程中的代码匹配及数据读取。
