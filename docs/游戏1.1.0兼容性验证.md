# 游戏 1.1.0 兼容性验证

验证日期：2026-10-30。目标：Deskrawl **1.1.0 / Steam build 26310087**，Windows x64。

## 新增内容及适配范围

对照[游戏官方更新公告](https://steamcommunity.com/app/4623570/announcements/)与本机实际元数据、程序集和资源核验：

- 仆从新增等级、经验、被动与主动技能培养、仆从装备及继承技能。本次新增只读仆从接口，读取已解锁仆从、出战状态、成长数值、继承槽位与借用技能；上限和解锁等级读取实际配置，不使用公告常量。
- 新增四件仆从装备（其中一件传说），补充装备部位、名称、图标与词条池。角色穿戴快照单独返回仆从装备，角色自动换装拒绝将其当作角色装备。黄金可汗之鞍的资源没有独立特殊效果或说明，不生成虚构效果文字。
- 新增世界首领、对应奖励、缰绳、神话代币、皇家宝箱等资源；同步本地物品、图标、效果和市场目录。新增猎人天赋、猎人项链的中毒伤害词条以及两个灵魂碎片容量生活技能节点。
- 游戏新增魔盒装备配方和金币费用。本次仅适配现有宝石、符文自动合成：按当前在线配方读取数量、概率、费用和解锁条件，按新接口提交符文配方，并核验费用变化；不自动执行黑雾装备重铸。
- 宝石等物品堆叠上限从实际资源读取，支持新版 999 上限；灵魂碎片容量根据生活技能动态计算，包含新增容量节点。
- 南瓜王接入托管重复刷图：在普通、噩梦、炼狱列表中选择，沿用单图复刷、双图轮换、成功通关计数、奖励收取与观星判断。读取原生世界首领入场状态、活动窗口和服务器时钟；列表显示共享每日剩余次数，未解锁、活动关闭或次数耗尽时不再提交入场。

本次未新增自动培养仆从、自动分配继承技能或代币兑换功能。自动推图仍只推进普通主线关卡，世界首领从重复刷图中选择。

## 接口与数据变更

- 更新背包、仓库、马车、角色、关卡、掉落预览、成长、商人、合成、拍卖行及重连使用的字段布局、混淆类绑定和动作入口。
- 重新核验 56 个动作入口，更新声明类型、签名、原生地址及代码指纹。兼容性基线包含 15483 个原生方法；继续核对字段、枚举、资源和代码逻辑，未关闭校验。
- 适配 ItemData 中新增的宝箱特殊掉落数组。资源提取按序列化长度定位后续字段，避免将内存字段偏移误用于资源文件。
- 详细掉落记录由列表改成最多保留 100 条的队列；按队列首尾、数量和版本读取，滚动后保留稳定记录索引。快照未通过核验时不提交读取游标，避免重复统计或提前消费记录。
- 处理新程序集的链式展开信息及无返回异常桩，使原生方法指纹覆盖完整代码，同时避免将跳转表误识别为顺序指令。
- 保留既有规则与配置；读取旧配置时在内存补齐新增仆从装备收纳字段，不覆盖原文件或重置其他偏好。

## 实机验证与限制

只读连接正在运行的 1.1.0，兼容性状态为已验证。背包、全部已解锁仓库页、角色属性、装备、关卡列表、成长、游戏统计、仆从成长、继承槽位、十类普通神秘商人报价及合成配方均读取正常，未发现容器读取问题。在线符文三档升级配方的金币费用分别为 100000、200000、500000，按服务器当前返回值使用。

检查时角色在主城，掉落预览正确返回等待战斗关卡状态。未验证 1.1.0 战斗中的真实掉落计划、完整托管循环或消耗动作；购买、合成、换装、上架、切图等接口本次以静态审查与离线回归覆盖，不能记为新版本实机操作验收。未安装动作分发器，未重启游戏或助手，未执行仆从培养或其他游戏写入。

### 南瓜王专项验证

核对实际 `WorldBossEntryState`、`SaveSystem`、`CloudClient` 和 `MapData` 的字段、常量及原生入口逻辑。当前版本每日共用 100 次入场，按游戏的 09:00 UTC 重置；在线模式使用服务器时钟偏移，活动窗口使用游戏固定的 UTC−7 偏移。时间范围从当前地图资源读取，不在助手中写死活动结束日期。入场调用原生传送接口，提交前重新核验次数，保留原生解锁、时间及次数检查。

次数耗尽或活动关闭后，先完成当前已入场关卡的奖励收取和回城整理，再暂停并保留统计。最后一次入场不会因为观星未命中而提前放弃；普通情况下观星退出仍会消耗游戏的入场次数，界面已提示。其余地图不受世界首领状态读取失败影响。

新增 13 项 Python 和 2 项前端用例，覆盖跨日重置、固定时区活动边界、在线／离线状态、三档难度共享次数、解锁限制、未知状态隔离、提交前次数变化、成功计数与轮换、最后一场奖励整理和观星跳过。实机只读连接在战斗中成功读取三档南瓜王选项，活动开放、今日剩余 100 次；未提交实际入场、消耗次数或验证真实南瓜王通关。

上述记录描述接口研究时的验证范围。之后仆从装备与南瓜王刷图开发版已由用户测试并确认通过；后补的三档南瓜王宝箱分类与自动开启使用资源、原生入口审查及离线回归验证。1.5.0 发布准备与直接升级验证另见[1.5.0 验收说明](1.5.0验收说明.md)，README 和更新说明经用户确认后才上传发布。
