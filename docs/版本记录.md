# 版本记录

## v1.1.2

- 装备预览显示词条数值，按属性类型展示百分比或普通数值。
- 使用已验证的游戏计算方式显示装备强化后的数值，计算时保留原始词条顺序。
- 命中已启用规则的词条显示绿色与 ✓；整件装备未达标时也能看到部分命中。
- 基础护甲、基础武器伤害与速度独立显示，不计入主副词条数量、不高亮。
- 数值展示不改变筛选规则：当前规则仍按不同词条类型的命中数量判断。
- 界面与逻辑已由用户确认。128 项自动检查和打包后实际游戏的只读连接验证通过。
- 发布源码的测试使用合成或脱敏用例，运行时不需要个人背包快照。

## v1.1.1

- 修正固定基础属性导致漏锁或抬高主词条命中数的问题。
- 主副词条分组不完整或读取未核验时，保持待核验状态。

## v1.1.0

- 使用 WebView2 独立窗体承载网页界面。
- 按职业、部位及名称配置特定传说装备的筛选规则。
- 提供全部解锁、选择锁定、按规则锁定与持续监控。
- 单文件 exe 自带必要字典与图标，规则保存在本机用户目录。
