# 版本记录

## v1.1.5 · 2026-10-09

- 顶部新增更新提示、发行记录入口及手动检查按钮；启动后自动检查 GitHub 正式 Release，每小时重新检查一次。网络错误或检查限流不会影响装备功能。
- exe 独立窗体支持「下载并更新（重启）」：先保存合法的未保存配置，下载至当前程序目录，核验文件大小、SHA256、Windows x64 格式与版本号。
- 下载成功后暂停助手的锁定和整理并等待当前操作结束，再退出、替换当前 exe、重新启动。保留原文件名与快捷方式、规则、整理设置和日志；新版本仍默认关闭监控和自动整理。
- 替换时保留旧程序备份，新窗体确认启动后清理；无法确认新程序启动时恢复旧程序。下载或校验失败不替换旧程序，源码模式只查看更新信息。
- 「背包与仓库」新增金色「✦ 主词条全中」标记及筛选项：四条随机主词条全部命中同一个启用组合才显示，不检查副词条，不跨组合拼接，不计基础属性。详情注明全中的组合。
- 特殊标记仅用于展示，不改变现有主副词条筛选、自动锁定或整理条件。
- 232 项自动检查通过，覆盖版本选择、下载中断、损坏文件、来源验证、未保存改动保护及主词条全中判断。

## v1.1.4 · 2026-10-09

- 每件装备可新增多个独立命名的词条组合，可复制、改名、启用 / 停用和删除；任意一个启用组合满足即符合规则。修复只有已存在多个组合时才显示「新增组合」的问题。
- 装备卡片显示启用 / 总组合数量，预览结果明确注明命中的组合，每个组合的主、副词条条件独立判断。
- 保留旧版规则与配置，导入导出包含每件装备的全部组合，导入后仍默认停用。
- 新增「日志」页签，支持分类、搜索和历史分页；日志保存在本机 SQLite 数据库，重启后保留。
- 连接后独立观察背包、仓库和马车，每 2 秒读取一次，无需开启自动锁定或整理。首次清单作为基线；之后记录完整读取中观测到的新增物品与数量增量。
- 每次锁定 / 解锁、手动 / 自动转移逐件记录名称、位置与数量。宝石合并、拆分堆叠记录每个实际来源和目标格，以及数量前后变化。
- 记录马车新增物品、马车 → 背包及背包 → 仓库的完整工具操作链，工具搬运不会再次算作新增掉落。确认提交后即记录，后续场景清理或读取出错不会丢失成功的搬运记录。
- 规则保存、导入导出、自动整理设置、连接、刷新、停止及操作失败均记录。
- 206 项自动检查通过；单文件 exe 的独立窗体、内置资源、配置和日志持久化及实际游戏只读连接已验证。

## v1.1.3 · 2026-10-09

- 支持背包与仓库双向移动实体装备、材料、宝石、符文和宝箱，保留数量、装备属性与锁定状态。
- 同种同等级宝石优先合并仓库中已有堆叠，满堆后使用已开放的空格。
- 在「背包与仓库」新增自动整理设置：马车按物品名称自动收取到背包、背包宝石自动入库、背包快满时装备自动入库。
- 马车物品支持按当前类型和搜索结果一键全选 / 全不选，保留其他筛选范围的选择；保存整理设置后生效。
- 装备入库可设置触发剩余空格、整理后预留空格，以及全部 / 已锁定 / 未锁定装备范围。
- 自动整理与新增装备锁定监控各自开启或暂停；整体停止、断开连接与退出会停止自动操作。
- 自动整理设置保存在当前用户目录；每次重新启动默认暂停，仓库或背包空间不足时等待。
- 修复战斗中增删装备导致注册表条目数校验误报：读取期间发生变化会重读；持续变化时保留监控、自动整理和待锁装备，等待下一轮。真正的数据完整性错误仍停止操作。
- 内置 36 种宝石和 199 种符文的图标与效果数据；宝石显示不同镶嵌部位效果，符文显示1级基础属性、等级成长、技能加成及套装效果。
- 图标与效果随程序打包，使用者无需提供游戏资产文件。效果预览不参与装备词条筛选。
- 软件顶部增加 GitHub 项目快捷入口和 Star 提示，点击链接在系统浏览器中打开项目；README 同步加入支持说明。
- 适配游戏 1.0.2（Steam build 25817367）：重建类型字段与程序地址校验，更新装备注册表、保存标记和搬运写屏障入口。
- 新增 48 种技能符文的图标与效果，共覆盖 36 种宝石、199 种实际符文；武器和宝石种类没有新增。
- 更新旧符文的套装效果文本；宝石堆叠上限读取游戏当前数据，支持新版每组 99 颗。
- 185 项自动检查通过，实际游戏的移动、堆叠、马车收取和监控修复已验证；本版由用户测试验收。
