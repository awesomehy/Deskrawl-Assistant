# Deskrawl 助手 · 实测经验收益

该功能用于记录实际刷图收益，与自动“刷图推荐”配合使用；现有正式 Release 尚不包含。

## 使用

1. 启动包含本功能的助手。游戏启动后，在助手顶部点击“连接游戏”。
2. 打开“经验收益”，选择计划刷图时间，默认 60 分钟。
3. “使用当前关卡 / 角色”可填入游戏当前信息；也可自行填写关卡名、难度、角色、配装和加成条件。同一关卡的不同条件不会合并。
4. 进入关卡前点击“开始采样”；完成结算并准备重开后点击“结束并保存”。经验读取可用时留空自动结算，也可手动填写本次获得经验。
5. 对准备比较的关卡重复采样。排行根据实测经验及用时更新，首位是当前选择口径下收益最高的关卡。
6. 已有经验及用时记录可直接从“手动录入已完成的关卡”加入。无效或误录样本可在“最近采样”删除。

样本仅保存在本机，重启后仍保留。未完成的计时不会在重启后恢复。结束读取失败时计时停止，手动补录时间不算入通关；也可取消该采样。

## 两种比较口径

**按平均经验速度**：`经验总和 / 耗时总和 × 计划时间`。多次样本使用加权速度，避免平均各次每小时速度产生偏差。该估算含最后一次未完成循环的平均进度，适合关卡过程中不断获取经验的情况。

**仅计算完整通关**：`floor(计划时间 / 平均循环耗时) × 平均经验`。适合只关心完成通关次数的比较；时间不足以完成一次的关卡收益计为零。按此口径切换排行及推荐。

例如每次获得 1000 经验、完整循环用时 40 分钟，一小时平均速度预计为 1500 经验，仅完整通关预计为 1000 经验。

结果是根据你的角色和样本估算，未测量关卡无法比较。建议每关至少采样 3 次，计入载入、结算、失败和重开耗时；变更配装、角色、难度或加成后使用新的条件标签。

## 数据保存与更新

个人配置、历史日志和经验样本沿用助手原有个人数据目录。经验记录保存在 `data/runtime/experience.sqlite3`，不会包含在源码或打包资源中。

采样中的计时和等待补录的记录尚未保存到数据库；退出或自动更新前请先结束并保存，或取消该采样。自动更新会检查这一状态，保留未保存采样并拒绝重启。

本机同一时间使用一个助手窗口；需要切换版本时，先正常退出当前助手再启动另一个版本。

## 验证及许可证

游戏普通等级经验可自动读取并跨升级累计；满级后的巅峰经验目前需手动填写。程序只读取角色经验，不更改经验、等级、关卡或存档。

自动检查覆盖经验效率、不同关卡及条件分组、时间口径、持久保存、计时异常和网页接口。功能版以相同游戏构建哈希校验为前提；版本不匹配时保留手动录入。
