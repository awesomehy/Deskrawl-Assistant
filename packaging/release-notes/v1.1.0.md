# v1.1.0 · 独立窗体版

## 更新内容

- 启动程序后直接打开 WebView2 助手窗体，界面采用网页样式，无需另外打开系统浏览器。
- 顶部显示连接游戏按钮与连接状态；连接后读取背包和仓库。
- 提供“装备筛选规则”和“背包与仓库”两个页签。规则页支持按职业、部位及名称选择传说装备，并显示装备图标。
- 为特定装备配置主词条类型与“至少命中 n 类”门槛；副词条可关闭，启用后两组均须达标。
- 提供全部解锁、锁定所选装备、按规则批量锁定及持续监控新增装备。
- 单文件程序内置运行组件、装备字典和 209 张图标；新用户无需安装 Python。
- 规则保存在本机用户目录，更新或移动程序仍可保留；支持导入导出。
- 最小化时监控继续；关闭窗体会停止监控并退出服务。重复启动复用已有助手，关闭时检查未保存的规则。

## 验证与版本差异

- 发布前通过 109 项自动检查，并完成独立 exe 启动、窗体退出、图标资源、规则持久化及实际游戏只读连接验证。
- 本版尚未包含 v1.1.1 对固定基础属性参与筛选的修复，日常使用建议下载 v1.1.2。

## 下载与使用

- 下载下方 `Deskrawl-Assistant-v1.1.0.exe`，双击即可运行，无需安装 Python。
- 若提示缺少 WebView2，可运行[微软官方安装程序](https://go.microsoft.com/fwlink/p/?LinkId=2124703)，联网安装后重新启动助手。
- 先正常退出正在运行的旧版，再启动本版。各版本共用规则目录 `%LOCALAPPDATA%\Deskrawl装备助手\`。
- 第三方组件许可见[许可说明](https://github.com/awesomehy/Deskrawl-Assistant/blob/main/packaging/release-notes/licenses-v1.1.0.txt)。
- exe SHA256：`8041fa2fdcb11b62fb26e07e33491a39d61ae1614743ff5ecba4eb928e7c4102`。

## 适配范围

Windows x64，需 WebView2 和 .NET Framework 4.6.2 或更新版本。适配已经核验的 Deskrawl Steam Build 25740305；游戏更新后需要重新核验。规则仍按词条类型数量判断，不提供数值门槛。

发行包不含个人规则、装备快照或运行日志。装备数据只在本机处理。未在另一台电脑或全新 Windows 虚拟机上完成测试。
