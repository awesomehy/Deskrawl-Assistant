# v1.1.1 · 基础属性筛选修复

## 更新内容

- 修正固定基础属性混入主副词条判断的问题，避免命中数量被抬高，或正常装备被误判为“待核验”而漏锁。
- 武器的基础“武器速度”“武器伤害”不参与筛选。
- 头盔、护肩、胸甲、裤子、手套、鞋子的基础“护甲”不参与筛选；“护甲加成”仍属于可筛选词条。
- 基础属性在装备详情中单独显示；匹配原因列出具体命中词条，方便核对规则。
- 旧筛选配置保留；编辑含基础护甲的旧规则时提示取消该项。
- 未知词条、分组无法核验或读取不完整的装备继续保持“待核验”，不自动锁定。

## 验证与版本差异

- 发布前通过 121 项自动检查，包含真实词条列表脱敏后的回归用例：基础属性不抬高数量、达标手套可匹配、不达标装备不通过。
- 打包后的独立 exe 完成窗体加载、资源读取、规则持久化及实际游戏只读连接验证。
- 词条数值显示与绿色命中高亮在 v1.1.2 提供，本版保留词条类型与匹配原因展示。

## 下载与使用

- 下载下方 `Deskrawl-Assistant-v1.1.1.exe`，双击即可运行，无需安装 Python。
- 若提示缺少 WebView2，可运行[微软官方安装程序](https://go.microsoft.com/fwlink/p/?LinkId=2124703)，联网安装后重新启动助手。
- 先正常退出正在运行的旧版，再启动本版。各版本共用规则目录 `%LOCALAPPDATA%\Deskrawl装备助手\`。
- 第三方组件许可见[许可说明](https://github.com/awesomehy/Deskrawl-Assistant/blob/main/packaging/release-notes/licenses-v1.1.1.txt)。
- exe SHA256：`1693f8bc0ee619f33e60620e804a95952b0c3015a69dd858868899487ac979d6`。

## 适配范围

Windows x64，需 WebView2 和 .NET Framework 4.6.2 或更新版本。适配已经核验的 Deskrawl Steam Build 25740305；游戏更新后需要重新核验。规则仍按词条类型数量判断，不提供数值门槛。

发行包不含个人规则、装备快照或运行日志。装备数据只在本机处理。未在另一台电脑或全新 Windows 虚拟机上完成测试。
