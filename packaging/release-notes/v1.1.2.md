# v1.1.2 · 词条数值与命中高亮

## 更新内容

- 装备预览在词条类型旁显示读取到的数值；按属性类型展示百分比或普通数值。
- 使用已经验证的游戏计算方式显示装备强化后的数值，保留原始词条顺序进行计算。
- 命中已启用筛选规则的词条显示绿色和 ✓，可直接看出哪些词条计入规则。
- 整件装备未达标时仍显示已经命中的词条；是否整体达标以“符合规则”结果及匹配原因判断。
- 基础护甲、基础武器伤害与速度独立显示，不计入主副词条数量，也不高亮。
- 未读取到的数值显示“未读取”，不会显示为零。
- 数值展示不改变筛选逻辑：主、副词条仍分别按不同类型的命中数量判断，不提供数值门槛。
- 延续 v1.1.1 的基础属性修复，以及独立窗体、背包/仓库批量操作和持续监控功能。

## 验证

- 128 项自动检查通过，覆盖数值和百分比换算、装备强化、部分命中高亮、基础属性排除及重复类型计数。
- 单文件 exe 完成独立目录启动、窗体加载、图标读取、规则持久化及实际游戏只读连接验证。
- 排版与交互逻辑已由用户实际查看并确认。
- GitHub 源码中的测试使用合成或脱敏用例，运行测试不需要个人装备快照。

## 下载与使用

- 下载下方 `Deskrawl装备助手-v1.1.2.exe`，双击即可运行，无需安装 Python。
- 若提示缺少 WebView2，可运行[微软官方安装程序](https://go.microsoft.com/fwlink/p/?LinkId=2124703)，联网安装后重新启动助手。
- 先正常退出正在运行的旧版，再启动本版。各版本共用规则目录 `%LOCALAPPDATA%\Deskrawl装备助手\`。
- 第三方组件许可见[许可说明](https://github.com/awesomehy/Deskrawl-Assistant/blob/main/packaging/release-notes/licenses-v1.1.2.txt)。
- exe SHA256：`2cdaf39314319d543914889d53651c2357a52de37dc0d2af52269654aa8dc725`。

## 适配范围

Windows x64，需 WebView2 和 .NET Framework 4.6.2 或更新版本。适配已经核验的 Deskrawl Steam Build 25740305；游戏更新后需要重新核验。规则仍按词条类型数量判断，不提供数值门槛。

发行包不含个人规则、装备快照或运行日志。装备数据只在本机处理。未在另一台电脑或全新 Windows 虚拟机上完成测试。
