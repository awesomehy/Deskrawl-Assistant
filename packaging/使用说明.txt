Deskrawl 装备助手 v1.5.1 · 南瓜王优先刷取、仆从装备分品质整理

适配 Deskrawl 1.1.0 / Steam build 26310087，Windows x64。
v1.4.6 和 v1.5.0 可直接升级，无需中间版本；已有规则、托管、整理、合成及同一 Windows 用户下的有效 Steam 凭证继续保留。
仆从装备按品质整理：黑雾传说固定锁定入库，普通传说和稀有可分别配置入库、出售或分解，已锁定装备继续保护。
旧版仆从装备统一处理方式迁移至两种品质，保留存放页；更早配置默认入库并沿用装备存放页，不自动增加出售权限。
南瓜王改为独立优先刷取开关，可单独设置难度；每日次数用尽、活动结束或尚未解锁后继续原副本配置，未开启原副本刷图时等待重置。
普通轮刷列表移除南瓜王，其成功次数单独记录，旧南瓜王配置自动迁移，最后一次入场不提前放弃。
修复棱彩之心等 8 件装备效果描述的占位符和缺失数值；优化南瓜王难度、次数和开关排版。
普通、噩梦、炼狱南瓜王宝箱及皇家宝箱接入回城开箱，锁定宝箱不自动开启；开箱后重新扫描奖励。
本版不提供仆从自动培养。
交易所上传和 Steam 市场出售正式开放，默认关闭；可按类别允许并按具体商品强制保留。
背包与仓库提供手动批量“上架交易所”，可选择同时出售到 Steam 市场；仅主城可用。
Steam 出售需要先开启上传并登录同一账号；官方登录后加密保存凭证，重启可恢复。
价格按买方含手续费总价，支持最低在售价与最高求购价；手机或邮件确认仍由用户完成。
上传忽略锁定状态，但穿戴、绑定、强化、有孔及身份不完整的物品不参与；无实例编号的堆叠材料暂不支持。
修复早期开发版上架配置迁移，已有托管预设保留；回退旧版前请恢复旧配置备份或转换新增上架字段。
修复神秘商人补货确认延迟导致托管停止：继续核验原请求，不重复补货或购买。
库存持续未恢复时，整理已购装备后跳过本轮消费；状态不可读或余额变化时仍暂停核验。
马车收集期间等待后重新读取，不因收取前暂态误停止；收取后不一致仍保留保护。
合成回执延迟时保留原请求继续核验，确认后单独恢复魔盒清理，不重复消耗。
修复符文合成后材料槽残留导致下一轮误暂停：原生清槽后回读核验，兼容旧版隐藏残留并保留玩家选材。
游戏目录按实际身份核验，兼容路径别名；更新检查使用 Windows 原生证书验证并自动重试。
修复结算弹窗已出现但辅助数据不一致时托管不继续推图；进图确认核验新旧计划，仍先拾取奖励再离开。
已有规则与本地设置继续保留。观星刷本暂时隐藏并停用，旧配置自动关闭；掉落预览与高价值监控继续可用。不自动连接游戏或开启托管。
宝石与符文自动合成继续正式开放，默认关闭；Steam报价继续作为参考价显示。
启动后每30秒匿名上报职业、等级及游戏累计时长、神圣装备和符文套装数量，用于 https://deskrawl.hhyan.me/ 社区统计。
不上传账号、角色名或装备明细，上报失败不影响托管。个人数据不随程序分发。

功能
- 托管模式位于第三个页签，运行时显示绿色状态和呼吸动画。
- 自动换装跳过佩戴等级不足的装备，取出和穿戴前重新核验等级；神圣仍禁止自动穿戴。
- 托管模式：自动换装、指定难度复刷/跨难度推图、奖励整理和累计掉落，主动停止先回城整理。
- 新用户默认装备仓库1/2/3页、符文4页，宝石/金条/传说缰绳5页；已有本地选择优先。
  未解锁页保留勾选，只使用实际开放格位；无目标时物品留在背包，等待/暂停，不借用其他分区。
- 神圣、黑雾装备及套装/宏伟符文禁止出售或分解，必须收纳；神圣装备禁止自动穿戴。
  主城地面和马车奖励未清空不能入图；整批装备先完成筛选锁定，才处理垃圾，最后开宝箱。
- 装备未命中处理和满仓备用策略按品质配置，旧装备返回背包，不自动移植宝石。
- 掉落预览：连接游戏后打开对应页签，在线进图显示全部波次计划，每2秒刷新，下一关替换、回城或断连清空。
  内置当前游戏602个物品ID、名称、图标及效果；符文按游戏品质配色。
  装备按基础属性、主词条和副词条分组，命中规则的词条高亮。
  可独立开启高价值掉落监控，发现神圣、黑雾装备、宏伟符文或符文套装时在本机保存原始计划和实际观测。
  计划尚未结算，实际获得以游戏结算为准；宝箱内物品、寻宝和采集奖励不提前推测。
  此独立预览已核验游戏1.1.0；未来版本需单独适配，无需开启自动锁定或整理。
- 背包与仓库显示远古、黑雾、神圣标签、强化等级、已镶嵌数量 / 总孔数。
- 显示当前角色属性与12个穿戴部位；身上装备使用独立弹窗预览，不切换列表侧栏。
- 预览镶嵌宝石的名称、图标和该部位生效属性，空孔单独显示。
- 换装攻击力按固定单体Boss、满血、无临时增益估算；战士/武僧2米，猎人/法师7米。
  战斗Buff、血量和距离不改变换装数值，永久属性变化重新计算；戒指分别比较两个替换位置。
  沿用游戏面板公式，不预测新传奇特效、技能等级、技能触发或实际战斗DPS，不自动转移宝石。
- 点击位置、物品等级、强化、孔位、锁状态、换装攻击力、规则结果表头的箭头，弹出筛选/排序菜单。
  多列筛选取交集，同列多选取并集；孔位按总孔数排序，未知数值排在末尾。支持全选/全不选、逐列清除及全部重置。
- 配置特定装备的主、副词条类型和至少命中数量；基础护甲、武器伤害和速度不参与随机词条筛选。
- 后台读取背包与仓库，显示数值及命中高亮，锁定所选装备、按规则锁定、全部解锁和监控新增装备。
- 双向移动实体装备、材料、宝石、符文及宝箱，保留数量、词条、强化与锁定状态。
- 同种同等级宝石优先堆叠，按游戏当前上限处理，1.1.0 支持每组 999 颗。
- 自动整理：按物品类型将马车物品收进背包；背包宝石和符文自动入库；背包快满时装备自动入库。
- 内置 36 种宝石和 199 种符文的图标及效果，包含游戏 1.0.2 新增的 48 种技能符文。
- 顶部提供 GitHub 项目入口。如果觉得本软件对你有帮助，欢迎点亮 Star。
- 每件装备可建立多个可命名词条组合，新增、复制、改名、独立启用或删除；任意一个启用组合满足即符合规则。
- 组合选择旁可删除当前组合，「管理组合」支持勾选、全选和批量删除。
- 导入规则时可选择全部启用或停用，仅影响新导入的组合，现有配置保留。
- 「复制到同类装备」支持复制当前或全部已保存组合，只允许同一部位；可追加或替换，重复组合自动跳过。
- 日志页签记录观测到的物品获取及工具的锁定、解锁、转移操作，包含位置、数量、宝石堆叠前后变化。
- 四条随机主词条全部在同一个启用组合中时显示金色「✦ 主词条全中」，不检查副词条，不改变锁定规则。
- 顶部自动检查 GitHub 正式发行版，每小时检查一次；支持手动检查、查看发行记录和一键下载更新。

开始使用
1. 双击 Deskrawl-Assistant-v1.5.1.exe，无需安装 Python，无需打开系统浏览器。
2. 启动 Deskrawl 并进入角色，点击顶部“连接游戏”。首次连接可能需要几秒钟。
3. 在“装备筛选规则”按职业、部位选择传说装备，勾选词条类型、填写至少命中数量，保存并启用。
   副词条可关闭；启用时主、副词条两组都满足才锁定。
4. 在“背包与仓库”勾选物品，点击“移入仓库”或“取回背包”。战斗中也可使用。
5. 展开“自动整理”，勾选需要的功能、配置马车物品及容量条件，点击“保存整理设置”。
   马车物品按装备、符文、宝石、宝箱、材料/其他类型选择，可点击“全选”或“全不选”。
   然后点击“启动自动整理”。此开关与“新增装备按规则锁定”的持续监控开关相互独立。
6. 自动整理每 2 秒检查一次：先处理宝石和背包容量，再收取选中的马车物品。
   “剩余空格 ≤”时触发装备入库，持续整理到“预留空格”目标或没有可移动的装备。
   仓库满时等待；马车收取需要背包空格，空间不足则保留物品；不出售或分解物品。
7. 每件装备的「新增组合」可配置另一种流派，「组合名称」可改名；只有启用并保存的组合参与筛选。
   主、副词条必须在同一个组合内满足；不同组合的命中条件不会互相拼接。
8. 日志支持分类、搜索和历史分页，重启后保留。连接后每 2 秒观察物品变化，无需启动自动锁定或整理。
   首次清单作为基线；两次读取之间瞬时出现又消失的物品可能无法观测。工具实际完成的转移逐次记录。

图标与效果
- 图标、中文名称、词条数据和效果说明随程序打包，不读取其他用户的本地图标文件。
- 宝石按镶嵌于武器、护甲、饰品分别展示效果。
- 符文预览显示1级基础加成、属性每级成长、技能加成与成长间隔；套装效果需满足对应件数。
  当前预览不计算特定符文实例的实际等级、角色技能最终加成或套装是否已经激活。

退出与配置
- 最小化后继续运行；关闭窗体或点电源按钮会退出助手并停止监控、自动整理。
- 自动整理偏好会保存，每次重新打开程序默认暂停，需要手动启动。
- “停止操作”、断开连接或全部解锁会暂停自动操作，防止立即再次锁定或搬运。
- 个人规则、整理设置与运行记录保存在 %LOCALAPPDATA%\Deskrawl装备助手\。
  config\lock-rules.json 为规则；config\automation.json 为自动整理设置。
  data\runtime\activity.sqlite3 为本机日志；更新或移动 exe 不会清空日志。
- 首次使用不包含开发者的个人规则或背包数据。换电脑可在页面导出/导入筛选规则。
- 再次双击会显示正在运行的独立窗口；旧版网页助手仍在运行时须先退出旧版。

当前适配范围
- 已验证基准为 Deskrawl 1.0.3，Steam Build 25973417。连接时自动检测新版本。
- 字段改名、类型序号或地址移动，且布局、枚举、资源及代码逻辑不变时，自动适配；新版本首次检查可能需要约一分钟。
- 新增或改变资源、字段类型/布局或逻辑变化时，需要我们维护。不能确认兼容性时不会操作物品。
- 顶部显示兼容性检测状态；连接期间游戏文件更新会停止操作，请重新连接检测。
- 重新适配在线仓库权限、装备保存标记和搬运写屏障；游戏临时禁止物品操作时不会写入。
- 52 件传说装备筛选；按词条类型数量判定，暂不支持词条数值门槛。
- 披风随机词条池尚不支持规则筛选，未揭示黑雾装备不会自动锁定。
- 只搬运实体物品；游戏按计数器保存的货币/虚拟材料不属于背包格子。
- 已被游戏出售或分解的物品无法找回。游戏自己的马车出售/分解设置仍会生效。
- 锁图标可能滞后，重新打开背包会刷新；助手显示实际读取的锁状态。
- 需要 Microsoft Edge WebView2 和 .NET Framework 4.6.2 或更新版本，Windows 10/11 通常已具备。
- 页面与游戏操作在本机运行，不上传装备数据。更换游戏安装盘符不会影响自动定位。
