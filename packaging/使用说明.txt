Deskrawl 装备助手 v1.1.2

新增：装备详情显示词条数值（含装备强化）与百分比；命中已启用规则的词条显示绿色及勾号。部分词条命中不代表整件装备已经达标，请同时查看筛选结果。

本版修正：基础护甲、武器基础伤害/速度不参与主副词条筛选，避免基础属性误计或造成漏锁。装备详情列出具体命中词条。旧配置保留；旧规则中的基础护甲勾选需在编辑时取消。
Windows x64 独立窗体单文件版 · 2026-10-08

使用方法
1. 把 Deskrawl装备助手-v1.1.2.exe 保存到电脑上，双击运行。无需安装 Python。
2. 稍等几秒，会直接显示装备助手窗体，界面与此前网页一致，无需打开系统浏览器。
3. 启动 Deskrawl，进入角色，点击页面顶部“连接游戏”。首次连接可能需要几秒钟。
4. 在“装备筛选规则”中按职业、部位找装备，勾选主词条并设置“至少 n 类”。
   副词条可关闭；启用时主、副两组都满足才锁定。保存规则并启用。
5. 在“背包与仓库”中刷新装备、勾选锁定、按规则批量锁定或全部解锁。
6. 开启“持续监控”后，会记录已有装备，只自动锁定之后新增且符合规则的装备。
   已有装备请点击“一键按规则锁定”。导入规则后默认停用，需要自行启用。

退出与数据
- 最小化窗体时后台监控仍可继续。关闭窗体或点右上角电源按钮会退出助手并停止监控。
- 关闭窗体时，若有未保存的规则改动，会提示是否放弃。
- 再次双击 exe 会显示已运行的助手窗体。旧版网页助手仍在运行时，请先退出旧版。
- 首次使用是空规则，不包含开发者的个人筛选配置或背包数据。
- 规则和运行记录保存在：%LOCALAPPDATA%\Deskrawl装备助手\
  规则文件：config\lock-rules.json；运行记录：data\runtime\。
  可在资源管理器地址栏输入上述目录；换电脑请用页面“导出 / 导入规则”。
- 转发 exe 或本压缩包即可；不要把自己本机的运行记录目录一起转发。

当前范围
- 需要 Microsoft Edge WebView2 运行环境（多数 Windows 10/11 已有）。
  若启动时提示缺少它，请运行本压缩包中的 MicrosoftEdgeWebview2Setup.exe，
  安装完成后重新双击助手。此安装程序由微软签名，安装时需要联网。
- 需要 .NET Framework 4.6.2 或更新版本，Windows 10/11 通常已具备。
- 适配 2026-10-08 验证的 Deskrawl 游戏版本，Steam Build 25740305。
  会自动寻找正在运行的游戏，不要求相同安装盘符或路径。
  游戏更新后若提示版本不匹配，需要重新适配助手；此时不会继续操作装备。
- 支持 52 件传说装备筛选；主、副词条按类型数量计数，暂不支持词条数值门槛。
- 披风的随机词条池尚不支持规则筛选，未揭示黑雾装备不会自动锁定。
- 装备必须先进入背包或仓库；已自动出售或分解的装备无法找回。
- 后台操作无需切回游戏、不占用鼠标键盘。游戏锁图标可能滞后，重新打开背包会刷新；
  助手清单显示读取到的实际锁状态。
- 监控每 2 秒检查一次。全部解锁会同时关闭持续监控，防止立即再次锁回。
- 网页和装备操作均在本机运行，不需要联网或登录，不上传装备数据。
